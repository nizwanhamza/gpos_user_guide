:::note[உங்கள் திட்டத்தைப் பொறுத்தது]
இந்தப் பக்கம் **POS கட்டணம், பண ஷிப்ட்கள் மற்றும் POS சாதனங்கள்** அம்சத்தைச் சேர்ந்தது. உங்கள் திட்டத்தில் அது இல்லையெனில், பட்டியில் தோன்றாது. [திட்டங்கள் மற்றும் அம்சங்கள்](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

நாளின் முதல் விற்பனைக்கு முன், டில்லில் **ஷிப்ட் திறந்திருக்க வேண்டும்** — [டில்லில் பண ஷிப்ட்கள்](/ta/till/shifts/) ஐப் பாருங்கள்.

## 1. பொருட்களைச் சேர்க்கவும்

இவற்றில் எதுவும் வலதுபுறம் உள்ள **விற்பனை** இல் பொருளைச் சேர்க்கும்:

- **பார்கோடை ஸ்கேன் செய்யுங்கள்.** முதலில் எங்கும் கிளிக் செய்யத் தேவையில்லை. பொதிப் பார்கோடு முழுப்
  பொதியையும் சேர்க்கும் (எ.கா. *24 பொதி*).
- **பார்கோடை ஸ்கேன் செய்யவும் அல்லது பெயர் அல்லது SKU ஐ தட்டச்சு செய்யவும்** பெட்டியில் பெயர் அல்லது SKU ஐ
  **தட்டச்சு** செய்து பொருளைத் தேர்ந்தெடுக்கவும் (சுட்டியால், அல்லது **↑ ↓** மற்றும் **Enter**).
- பார்கோடு கிடைக்கவில்லையா? உங்கள் திட்டத்தில் இருந்தால், <span class="ui">புதிய பொருளாகச் சேர்</span> ஐத் தேர்ந்தெடுத்து
  பெயர், விலை, வரியை உள்ளிட்டு உடனே விற்கவும் (காசாளர்களுக்கு மேலாளரின் PIN தேவை) —
  [Add a product at the till](/ta/till/add-product-at-till/) (ஆங்கிலம்).
- பார்கோடு இல்லாத பொருட்களுக்கு **விரைவுத் தேர்வுப் பொத்தானைத் தட்டுங்கள்**.

### எடைக்கு விற்கப்படும் பொருட்கள்

எடைக்கு விற்கப்படும் பொருட்களுக்கு டில் **தராசில் எடை (kg)** கேட்கும். எடையைத் தட்டச்சு செய்யவும், எ.கா.
`1.250`, பின்னர் <span class="ui">விற்பனையில் சேர்</span> ஐத் தேர்ந்தெடுக்கவும்.

## 2. விற்பனையைச் சரிபார்க்கவும்

ஒவ்வொரு வரிக்கும் நீங்கள்:

- <span class="ui">இன்னும் ஒன்று</span> / <span class="ui">ஒன்று குறைவு</span>; அல்லது
- வரியில் <span class="ui">திருத்து</span> ஐத் தேர்ந்தெடுக்கவும் (**F1** கடைசியாகச் சேர்த்ததைத் திருத்தும்): **அளவு**, **வகை**
  (வேறு அளவு/நிறம்), **தள்ளுபடி**, அல்லது <span class="ui">பொருளை நீக்கு</span>.

கீழே **துணைத் தொகை**, **வரி** (அல்லது *வரி அடங்கியது*) மற்றும் **மொத்தம்** காட்டப்படும்.

மீண்டும் தொடங்க வேண்டுமா? <span class="ui">அழி</span> அனைத்து வரிகளையும் நீக்கும் (உறுதிப்படுத்தக் கேட்கும்).

## 3. வாடிக்கையாளரைச் சேர்க்கவும் (விருப்பம்)

வாடிக்கையாளரை இணைத்து அவர்களின் தள்ளுபடியைத் தானாகப் பயன்படுத்த <span class="ui">வாடிக்கையாளர்</span> (**F3**)
ஐத் தேர்ந்தெடுக்கவும். சேர்க்காவிட்டால், செலுத்தும்போது டில் **இந்த விற்பனைக்கு வாடிக்கையாளர்?** எனக் கேட்கும்:
<span class="ui">வாடிக்கையாளரைச் சேர்</span> அல்லது <span class="ui">தவிர் — இப்போது செலுத்து</span>. **தொலைபேசி எண் அல்லது பெயர்** ஐத் தட்டச்சு செய்யவும், அல்லது <span class="ui">புதிய வாடிக்கையாளர்</span>
ஐத் தேர்ந்தெடுத்து <span class="ui">சேமித்து விற்பனையில் சேர்</span>.

## 4. பணம் பெறுங்கள்

1. <span class="ui">செலுத்து</span> ஐத் தேர்ந்தெடுக்கவும் அல்லது **F4** ஐ அழுத்தவும்.
2. **கட்டண முறை** ஐத் தேர்ந்தெடுக்கவும். **பணம்** எனில் **பெறப்பட்ட பணம்** ஐ உள்ளிடவும் (அல்லது
   <span class="ui">சரியான தொகை</span> ஐத் தேர்ந்தெடுக்கவும்); டில் **மீதி** ஐக் காட்டும்.
3. <span class="ui">விற்பனையை முடி</span> ஐத் தேர்ந்தெடுக்கவும்.

**அட்டை, QR மற்றும் வங்கிப் பரிமாற்றம்:** GPOS அட்டையிலிருந்து பணம் எடுப்பதில்லை. முதலில் உங்கள் வங்கியின்
முனையம் அல்லது செயலியில் பணத்தைப் பெற்று, முனையம் காட்டும் **அங்கீகாரக் குறியீடு / குறிப்பு** ஐத் தட்டச்சு செய்யவும்.

**பகுதியாகச் செலுத்துதல்:** முதல் முறையைத் தேர்ந்தெடுத்து **தொகை** ஐ மாற்றி, மீதியை வேறு முறையில் பெறுங்கள்.

டில் *விற்பனை முடிந்தது · ரசீது …* மற்றும் *கொடுக்க வேண்டிய மீதி: …* என்று காட்டும்.

## 5. மீதி மற்றும் ரசீது

டில் கொடுக்க வேண்டிய **மீதி** ஐப் பெரிதாகக் காட்டி **வாடிக்கையாளருக்கு ரசீது அச்சிடவா?** எனக் கேட்கும்:

- <span class="ui">ரசீதை அச்சிடு (80 mm)</span> — **Enter** அல்லது **F5**; அல்லது
- <span class="ui">Go Green — ரசீது வேண்டாம்</span> — **Esc**.

டில் அமைப்புகளில் **ஒவ்வொரு விற்பனைக்கும் பின் அச்சிடு** இயக்கப்பட்டிருந்தால், கேட்காமல் உடனே அச்சிடும். கடைசி ரசீதை
மீண்டும் அச்சிட **F5**. பழைய விற்பனைகள்: **F9** → விற்பனை → மீள் அச்சு, அல்லது முழுப் பக்க விலைப்பட்டியலுக்கு
<span class="ui">A4 அச்சிடு</span>. மீள் அச்சுகள் **COPY** எனக் குறிக்கப்படும்.

## இணைப்பில்லாமலும் வேலை செய்யும்

இவை அனைத்தும் **இணையம் இல்லாமலும்** வேலை செய்யும். விற்பனை டில்லில் சேமிக்கப்பட்டு, இணைப்பு திரும்பியதும்
நிர்வாக அலுவலகத்துக்கு அனுப்பப்படும்.

:::danger[டில்லின் உலாவித் தரவை ஒருபோதும் அழிக்காதீர்கள்]
உலாவித் தரவை அழிப்பது அல்லது incognito பயன்முறையைப் பயன்படுத்துவது இன்னும் அனுப்பக் காத்திருக்கும்
விற்பனைகளை நீக்கிவிடும்.
:::

## விசைப்பலகைக் குறுக்குவழிகள்

டில்லிலும் இந்தப் பட்டியல் உள்ளது: மேல் வலதுபுற **விசைப்பலகைப் பொத்தான்**, அல்லது **Ctrl + K**.

| விசை | செயல் |
|------|-------|
| **F1** | கடைசியாகச் சேர்த்த பொருளைத் திருத்து (அளவு, வகை, தள்ளுபடி) |
| **F2** | ஸ்கேன் பெட்டிக்குச் செல் |
| **F3** | விற்பனைக்கான வாடிக்கையாளர் |
| **F4** | செலுத்து (வாடிக்கையாளர் இல்லையெனில்: F3 சேர்க்கும், மீண்டும் F4 இல்லாமல் செலுத்தும்) |
| **F5** | கடைசி ரசீதை மீண்டும் அச்சிடு |
| **F6** | விற்பனையை நிறுத்தி வை |
| **F7** | நிறுத்தி வைத்த விற்பனைகள் |
| **F8** | முழு விற்பனைக்கும் தள்ளுபடி |
| **F9** | விற்பனைகள்: மீள் அச்சு, A4, திருப்பல், ரத்து |
| **F10** | ஷிப்ட்: பணம் உள்/வெளி, X அறிக்கை, மூடு |
| **F11** | முழுத் திரை இயக்கு/அணை |
| **F12** | டில்லைப் பூட்டு |
| **Num +** / **Num −** | கடைசிப் பொருளில் ஒன்று கூடுதல் / குறைவு |
| **Ctrl + Delete** | விற்பனையை அழி (முதலில் கேட்கும்) |
| **↑ ↓ Enter** | தேடல் முடிவைத் தேர்ந்தெடுத்துச் சேர் |
| **Esc** | சாளரத்தை மூடு |

உலாவியின் குறுக்குவழிகள் (மீண்டும் ஏற்றுதல், அச்சு, zoom…) டில்லில் முடக்கப்பட்டுள்ளன, எனவே தவறான விசையால் விற்பனை இழக்கப்படாது.
