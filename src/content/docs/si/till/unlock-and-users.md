:::note[ඔබේ සැලැස්ම මත රඳා පවතී]
මෙම පිටුව **POS ගෙවීම්, මුදල් මාරු සහ POS උපාංග** විශේෂාංගයට අයත්ය. ඔබේ සැලැස්මේ එය නොමැති නම්, මෙනුවේ එය නොපෙනේ. [සැලසුම් සහ විශේෂාංග](/si/getting-started/plans/) බලන්න.
:::

අයකැමිවරුන් ටිල් එකේ මුරපද ටයිප් නොකරයි. ඔවුන් තම නම තෝරා ඉලක්කම් 6ක **POS PIN** එක ඇතුළත් කරයි.
මෙය **නොබැඳිව** ද ක්‍රියා කරයි.

## අගුළු හරින්න

1. **ටිල් එක භාවිතා කරන්නේ කවුද?** තිරයේ ඔබේ නම තෝරන්න.
2. අංක පුවරුවෙන් (හෝ යතුරු පුවරුවෙන්) **ඔබේ PIN ඇතුළත් කරන්න**.

ලැයිස්තුවේ නැද්ද? ලැයිස්තුව පෙන්වන්නේ **POS PIN එකක් ඇති** සහ **මෙම ශාඛාවේ විකිණීමට ඉඩ ඇති** අයයි.
**සේවකයින්** තුළ ඔබේ PIN සැකසීමට පරිපාලකගෙන් ඉල්ලන්න, හෝ **මගේ ගිණුම** තුළ ඔබම එය සකසන්න.
ටිල් එක ඊළඟ සමමුහුර්තයේදී එය ලබා ගනී.

*තවම අයකැමිවරු නැත* ලෙස පෙන්වන්නේ නම්, මෙම ශාඛාව සඳහා කිසිවෙකුට තවම PIN එකක් නැත.

PIN නීති: හරියටම **ඉලක්කම් 6**; එකම ඉලක්කම නැවත නැවත නොවිය යුතුය (`111111`); අනුපිළිවෙළක් නොවිය
යුතුය (`123456` හෝ `654321`).

## වැරදි PIN

**වැරදි PIN 5කට** පසු ටිල් එක එම පුද්ගලයා මිනිත්තු 5ක් අගුළු දමයි, සහ සෑම වරකම රැඳී සිටීම දිගු වේ.
කොපමණ කාලයක් රැඳී සිටිය යුතුදැයි ටිල් එක පෙන්වයි.

## අගුළු දැමීම සහ පරිශීලකයා වෙනස් කිරීම

- කවුන්ටරයෙන් ඉවත් වන විට <span class="ui">අගුළු දමන්න</span> තෝරන්න. ටිල් එක නැවත PIN එකක් ඉල්ලයි.
- සගයෙකුට භාර දීමට <span class="ui">පරිශීලකයා වෙනස් කරන්න</span> තෝරන්න — ටිල් එක *ටිල් එක භාවිතා
  කරන්නේ කවුද?* වෙත ආපසු යයි. අගුළු තිරයේ <span class="ui">වෙනත් කෙනෙක්</span> තේරීමෙන් ද සගයෙකුට පිවිසිය හැක.
- භාවිතයක් නැතිව **මිනිත්තු 10කට පසු ටිල් එක ස්වයංක්‍රීයව අගුළු වැටේ**.

:::tip
ටිල් එකේ කරන සෑම දෙයක්ම — විකුණුම්, වට්ටම්, ආපසු ගෙවීම්, මුදල් ගැනීම්, අනුමැතීන් — එය අගුළු හැරි
පුද්ගලයා යටතේ වාර්තා වේ. ඔබ ඉවත් වන විට සෑම විටම ටිල් එක අගුළු දමන්න. ඔබේ PIN කිසිවෙකුට නොකියන්න.
:::

## ඔබට කළ හැකි දේ

ටිල් එක ඔබේ භූමිකාවට ඉඩ දෙන දේ පෙන්වයි. ඔබේ සීමාවට වඩා වැඩි වට්ටම්, ආපසු දීම් සහ අවලංගු කිරීම්
සඳහා **කළමනාකරු අනුමැතිය** අවශ්‍ය විය හැක: <span class="ui">කළමනාකරු අනුමැතිය</span> තෝරා, අනුමත
කරන්නා තෝරන්න, ඉන්පසු කළමනාකරු **තමන්ගේ PIN එක** ටිල් එකේ ඇතුළත් කරයි.
