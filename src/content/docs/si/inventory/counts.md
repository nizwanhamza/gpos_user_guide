**Stock counts** plan feature එකක් (ඒකට **Stock control** ඕන). ඒක නැත්නම් **Counts** tab එක පෙනෙන්නේ නැහැ.
[Plans and features](/si/getting-started/plans/) බලන්න.
:::

**Stock count** එකකින් shelves වල තියෙන දේ GPOS බලාපොරොත්තු වෙන දේ එක්ක සසඳලා, differences adjustments ලෙස post කරනවා. හැම item
එකක්ම **ගණන් කරපු මොහොතේ** system level එක තියාගන්නවා, ඒ නිසා **count එකක් අතරතුරත් tills වලට දිගටම විකුණන්න පුළුවන්**. ගණන්
නොකරපු items එහෙමම තියෙනවා.

## Count එකක් පටන් ගන්න

1. **Inventory → Counts** → <span class="ui">New count</span> වෙත යන්න.
2. **Store** එක තෝරන්න.
3. **What to count** — *Everything in the store*, නැත්නම් category එකක් (sub-categories ඇතුළුව).
4. ගණන් කරන අයට system quantity එක **නොපෙනෙන්න** ඕන නම් **Blind count** tick කරන්න — එතකොට වඩා අවංක counts ලැබෙනවා.
5. <span class="ui">Start count</span> තෝරන්න.

## ගණන් කරන්න

Count එකේ *… of … items counted* පෙන්නනවා.

- Item එකකට යන්න **barcode / SKU එකක් scan කරන්න හෝ type කරන්න**, <span class="ui">Find</span> තෝරලා ගණන් කරපු quantity එක දාන්න.
  මේ count එකේ නැති barcode එකක් report කරනවා.
- Filters භාවිතා කරන්න: **All**, **Not counted**, **Counted**, **Differences**.

ගණන් කරලා ඉවර වුණාම <span class="ui">Finish counting</span> තෝරන්න. Count එක **In review** වෙනවා. ආපසු යන්න <span class="ui">Count more</span> තෝරන්න.

## Review කරලා post කරන්න

Review එකේ හැම item එකකටම **System** quantity එක, **Counted** සහ **Difference** එක, සහ **Difference in value** එක පෙනෙනවා. වැරදි
වගේ පෙනෙන ඕනෑම දෙයක් ආයෙත් ගණන් කරන්න.

<span class="ui">Post differences</span> තෝරන්න. ගණන් කරපු හැම item එකක්ම ඒකේ difference එකෙන් adjust වෙනවා. **මේක undo කරන්න බැහැ.**

ඕන නැති වුණාද? <span class="ui">Cancel count</span>.

Statuses: *Counting* → *In review* → *Posted* (හෝ *Cancelled*).
