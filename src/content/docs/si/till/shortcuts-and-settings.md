## Keyboard shortcuts

මේ list එකම till එකෙත් තියෙනවා: උඩ දකුණු පැත්තේ **keyboard button** එක, නැත්නම් **Ctrl + K**.

### විකුණනකොට

| Key | කරන දේ |
|-----|--------|
| **F1** | අන්තිමට add කළ item එක edit කරන්න: quantity, variant, discount |
| **F2** | Scan box එකට යන්න |
| **F3** | Sale එකට customer (phone හෝ නමින් හොයන්න, නැත්නම් අලුත් කෙනෙක් add කරන්න) |
| **F4** | Pay. Customer කෙනෙක් නැත්නම් till එක මුලින් අහනවා: **F3** (හෝ Enter) එකෙන් කෙනෙක් add කරනවා, ආයෙත් **F4** එකෙන් customer නැතුව pay කරනවා |
| **F5** | අන්තිම receipt එක ආයෙත් print කරන්න |
| **F6** | Sale එක hold කරන්න |
| **F7** | Hold කරපු sales (resume හෝ discard) |
| **F8** | මුළු sale එකටම discount |
| **Num +** / **Num −** | අන්තිම item එකෙන් එකක් වැඩියෙන් / අඩුවෙන් (number pad එක, මොකුත් type කරලා නැත්නම්) |
| **Ctrl + Delete** | Sale එක clear කරන්න (මුලින් අහනවා) |
| **↑ ↓**, **Enter** | Search result එකක් (හෝ customer කෙනෙක්) තෝරලා add කරන්න |

### Pay කරනකොට සහ sale එකට පස්සේ

| Key | කරන දේ |
|-----|--------|
| **F4** හෝ **Enter** | Pay window එකේ: sale එක complete කරන්න (හෝ part payment එක add කරන්න) |
| **Enter** හෝ **F5** | Sale එකට පස්සේ: receipt එක print කරන්න |
| **Esc** | Sale එකට පස්සේ: Go Green — receipt එකක් නැහැ |
| **Enter** | Customer search එකේ කවුරුත් හම්බ නොවුණාම: type කරපු number එක හෝ නම අලුත් customer කෙනෙක් ලෙස add කරන්න |

### Shift, sales සහ till එක

| Key | කරන දේ |
|-----|--------|
| **F9** | Sales: receipt එකක් හොයන්න, reprint කරන්න, **A4** වල print කරන්න, items return කරන්න හෝ void කරන්න |
| **F10** | Shift: cash in/out, X report (receipt printer හෝ **A4**), close |
| **F11** | Full screen on / off |
| **F12** | Till එක lock කරන්න |
| **Ctrl + K** | Keys list එක |
| **Esc** | Open වෙලා තියෙන window එක close කරන්න |

ඕන නම් කෙලින්ම type කරන්න හෝ scan කරන්න පටන් ගන්න — till එක ඒක scan box එකට යවනවා. Function keys කවදාවත් scan box එකට
යන්නේ නැහැ, ඒ නිසා barcode scanner එක එක්ක ගැටෙන්නේ නැහැ.

### Browser shortcuts off කරලා

වැරදිලා key එකක් එබුණොත් page එක reload වෙන එක, screen එක print වෙන එක හෝ sale එකක් මැද till එකෙන් එළියට යන එක නවත්වන්න,
till එක browser එකේම shortcuts ignore කරනවා — reload (F5, Ctrl + R), print (Ctrl + P), find, zoom, back සහ forward, සහ text
fields වලින් පිට right-click menu එක. Copy, paste, cut, undo සහ select all හැම field එකකම දිගටම වැඩ කරනවා.

**Ctrl + W**, **Ctrl + T** සහ **Alt + F4** වගේ keys කිහිපයක් computer එකට අයිතියි, කිසිම web page එකකට ඒවා off කරන්න බැහැ.
ඒවා වළක්වන්න till එක full screen එකේ [installed app](/si/till/set-up-a-till/) එකක් ලෙස run කරන්න.

## Till settings

Till එකේම settings හොයන්න sync panel එක open කරන්න (status bar එක තෝරන්න). ඒවා අදාළ වෙන්නේ **මේ device එකට** විතරයි.

### Receipt printing

- **Receipt paper** — *58 mm* හෝ *80 mm* (default 80 mm).
- **Receipts** — automatic print කරන්න **Print after each sale** tick කරන්න.

Receipts print වෙන්නේ browser එක හරහා device එකේ install කරපු printer එකට. Receipt printer එක **default printer** එක ලෙස set
කරන්න, Chrome හෝ Edge වල print dialog එකේ headers සහ footers off කරන්න. Dialog එකක් නැතුව silent printing වලට, Chrome එකේ
*kiosk printing* option එක ගැන ඔබේ IT support එකෙන් අහන්න.

Print වෙන දේ (නම, header lines, footer, tax number) set කරන්නේ [Business settings](/si/business/settings/) හි *Receipts* කොටසේ.

### Screen

- **Screen** (sync panel එකේ) — browser එක ඉඩ දෙනවා නම්, till එක open කරලා තියෙනකම් screen එක on තියාගන්නවා.
- **Top bar** එකේ: ලොකු buttons සහ prices වලට <span class="ui">Larger text</span> / <span class="ui">Normal text</span>, සහ
  <span class="ui">Full screen</span> / <span class="ui">Exit full screen</span>.

### Scan sounds

Scan කරනකොට beep එක **On** හෝ off කරන්න.
