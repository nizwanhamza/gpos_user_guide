## Discount එකක් දෙන්න

- **එක line එකකට:** line එකේ <span class="ui">Edit</span> තෝරා (අන්තිම item එකට **F1**) ඊට පස්සේ <span class="ui">Add a discount</span>.
- **මුළු sale එකටම:** <span class="ui">Discount on the whole sale</span> තෝරන්න (හෝ **F8** ඔබන්න).

ඊට පස්සේ:

1. **Percentage** (උදා. `10` %) හෝ **Amount** (උදා. `100.00` අඩු කිරීමක්) තෝරන්න.
2. **Reason** එකක් තෝරන්න හෝ type කරන්න — *Damaged*, *Regular customer*, *Price match*, නැත්නම් ඔබේම වචන. Reason එකක් හැම
   විටම අනිවාර්යයි.
3. කොච්චර අඩු වෙනවාද කියලා preview එකේ පෙන්නනවා. <span class="ui">Apply discount</span> තෝරන්න.

වෙනස් කරන්න හෝ අයින් කරන්න, ආයෙත් open කර <span class="ui">Remove discount</span> තෝරන්න.

## Limits

ඔබේ business එක [Settings](/si/business/settings/) හි limits දෙකක් set කරනවා:

- **ඔබේම limit එක** — ඔබට තනියම දෙන්න පුළුවන් ප්‍රමාණය. මුලින් cashiers ට ඒක **0 %**, ඒ නිසා හැම cashier discount එකකටම manager ඕන.
- **Business limit එක** — ඕනෑම කෙනෙකුට දෙන්න පුළුවන් උපරිමය. ඊට වැඩි නම් till එකේ *Above the business limit of … % — not
  possible.* කියලා පෙන්නනවා.

**Customer discount** එකක් (customer ගේ profile එකෙන්) automatic apply වෙනවා, approval ඕන නැහැ.

## Manager approval

Discounts ඔබේ limit එකට වඩා වැඩි නම්, sale එකේ *The discounts are above your limit: a manager must approve them.* කියලා පෙන්නනවා.

1. <span class="ui">Manager approval</span> තෝරන්න.
2. Approve කරන කෙනා තෝරන්න — list එකේ POS PIN එකක් තියෙන සහ මේ branch එකට access තියෙන managers පෙන්නනවා.
3. Manager till එකේ **තමන්ගේ PIN** එක type කරනවා.

Sale එකේ *Approved by {name}* පෙන්නනවා. ලොකු cash outs, returns සහ voids වලටත් එකම approval screen එක භාවිතා වෙනවා.

Till එකේ *No manager can approve on this till* කියලා පෙන්නනවා නම්, manager කෙනෙකුට POS PIN එකක් සහ මේ branch එකට access ඕන.

## Discounts පෙනෙන තැන්

Discounts receipt එකේ print වෙනවා (*You saved …*), **Sales** හි sale එකේ පෙනෙනවා, සහ දුන්නේ කවුද, approve කළේ කවුද කියලා
**Discounts** report එකේ list කරනවා.
