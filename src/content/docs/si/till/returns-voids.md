| Refund | ගෙවපු විදිහටම | ඔබ තෝරන method එකට |

දෙකටම **open shift** එකක් ඕන (refunds යන්නේ ඒකේ drawer එකෙන්), සහ ඔබේ role එකෙන් ඉඩ නැත්නම් **manager ගේ approval** එක.

## Sale එක හොයන්න

1. **Sales on this till** open කරන්න <span class="ui">Sales</span> (**F9**) තෝරන්න. මෙතැනින් receipt එකක් reprint කරන්නත්,
   full-page invoice එකකට <span class="ui">Print A4</span> කරන්නත් පුළුවන්.
2. **Search receipt number**, නැත්නම් list එකෙන් sale එක තෝරන්න. ඉක්මන් ක්‍රමය: **receipt එකේ පහළ තියෙන barcode එක scan
   කරන්න** — till එකේ search box එකේ හෝ මෙතන — sale එක වහාම open වෙනවා.
3. **වෙනත් till එකක** sale එකක්ද? Receipt number එක type කර <span class="ui">Find … (another till)</span> තෝරන්න — මේකට internet ඕන. වෙනත් till එකක receipt එකක් scan කළොත් ඒක automatic හොයනවා.

## Items return කරන්න

1. Sale එකේ <span class="ui">Return</span> තෝරන්න (ඊට පස්සේ <span class="ui">Return items</span>).
2. හැම line එකකටම **Quantity to return** දාන්න (හෝ <span class="ui">All</span>). විකුණපු ප්‍රමාණය සහ දැනටමත් return කරපු
   ප්‍රමාණය screen එකේ පෙන්නනවා.
3. **Reason** එකක් තෝරන්න — *Faulty*, *Wrong item*, *Changed mind* හෝ ඔබේම එකක්.
4. Item එක ආයෙත් විකුණන්න පුළුවන් නම් **Back to stock (resellable)** tick කරන්න. Damaged goods වලට untick කරලා තියන්න — ඒවා
   restock නොකළ ලෙස record වෙනවා.
5. **Refund to** තෝරන්න — උදා. *Cash* — card, QR හෝ bank refunds වලට terminal එකෙන් හෝ app එකෙන් **Refund reference** එක
   type කරන්න. Cash නොවන method එකකට ආපසු දෙන්න පුළුවන් ඒකෙන් ගෙවපු ගණන දක්වා විතරයි; ඉතුරු ටික cash වලින් refund කරන්න.
6. <span class="ui">Refund {amount}</span> තෝරා, ඇහුවොත් manager ගේ approval එක ගන්න.

Original receipt number එක එක්ක **RETURN / REFUND** receipt එකක් print වෙනවා.

## Sale එකක් void කරන්න

1. Sale එකේ <span class="ui">Void</span> තෝරන්න (ඊට පස්සේ <span class="ui">Void sale</span>).
2. **Reason** එකක් තෝරන්න. ඒක **ගෙවපු විදිහටම refund වෙන** හැටි screen එකේ පෙන්නනවා.
3. <span class="ui">Void the sale</span> තෝරා, ඇහුවොත් approval එක ගන්න.

**VOID** receipt එකක් print වෙනවා.

## දැනගන්න හොඳ දේ

- Offline ඉන්නකොට till එක දන්නේ **මේ till එකේ** කරපු returns විතරයි.
- *This sale is older than the business's return window* — return window එක පහු වෙලා.
- Returns සහ voids **Sales** හි (*Returned*, *Partly returned*, *Voided*) සහ **Refunds & voids** report එකේ පෙනෙනවා.
