இன்னும் GPOS பயன்படுத்தவில்லையா? இணையத்தில் விண்ணப்பிக்கவும். GPOS இல் ஒருவர் ஒவ்வொரு விண்ணப்பத்தையும்
மதிப்பாய்வு செய்து, பொதுவாக **சில வேலை நாட்களுக்குள்** உங்களுக்கு மின்னஞ்சல் அனுப்புவார். விண்ணப்பம்
அங்கீகரிக்கப்பட்ட பிறகே உங்கள் வணிகக் கணக்கு உருவாக்கப்படும்.

**விண்ணப்பிக்க: [https://app.gpos.lk/register](https://app.gpos.lk/register)** — அல்லது
[உள்நுழைவுப் பக்கத்தில்](https://app.gpos.lk) **புதிய வணிகமா? கணக்கிற்கு விண்ணப்பிக்கவும்** ஐத் தேர்ந்தெடுக்கவும்.

:::note
*தற்போது இணையத்தில் புதிய விண்ணப்பங்களை ஏற்கவில்லை* என்று காட்டினால், GPOS Support ஐத் தொடர்பு கொள்ளுங்கள்;
அவர்கள் உங்கள் வணிகத்தை உங்களுக்காக அமைப்பார்கள்.
:::

## தொடங்கும் முன்

- வணிகப் பெயர், பதிவு செய்திருந்தால் **வணிகப் பதிவு (BR) எண்** மற்றும் பதிவு செய்யப்பட்ட **சட்டப் பெயர்**;
- வணிக முகவரி, தொலைபேசி மற்றும் மின்னஞ்சல்;
- **உங்கள் சொந்த மின்னஞ்சல் முகவரி** — அங்கீகரிக்கப்பட்டதும் அதன் மூலம் உள்நுழைவீர்கள்;
- உங்கள் கைபேசி எண்.

## 1. விண்ணப்பத்தை நிரப்புங்கள்

**உங்கள் வணிகம்** பகுதியில்: வணிகப் பெயர், வணிக வகை, சட்ட வடிவம், பதிவு நிலை (நிறுவனம் பதிவு செய்யப்பட்டிருக்க
வேண்டும்), பதிவு எண், சட்டப் பெயர் (நிறுவனத்துக்குக் கட்டாயம்), முகவரி, நகரம், மாவட்டம், வணிகத் தொலைபேசி மற்றும்
மின்னஞ்சல், இணையதளம் (விருப்பம்), கிளைகளின் எண்ணிக்கை, தற்போது பயன்படுத்தும் POS அமைப்பு (விருப்பம்).

**நீங்கள் விரும்பும் வணிகக் குறியீடு** — உங்கள் வணிகத்தில் அனைவரும் உள்நுழையப் பயன்படுத்தும் சுருக்கக் குறியீடு,
எ.கா. `lanka-mart` (சிறிய எழுத்துகள், இலக்கங்கள், hyphen). அங்கீகரிக்கும்போது உறுதிப்படுத்துவோம்; **பின்னர் மாற்ற முடியாது**.

**உங்களைப் பற்றி** பகுதியில்: முழுப் பெயர், வணிகத்தில் உங்கள் பங்கு (உரிமையாளராக இருக்க வேண்டியதில்லை, ஆனால்
விண்ணப்பிக்க அதிகாரம் இருக்க வேண்டும்), கைபேசி எண், மின்னஞ்சல் மொழி மற்றும் **உங்கள் மின்னஞ்சல்** (அங்கீகரிக்கப்பட்டதும் உள்நுழைய).

பின்னர்:

1. **இந்த வணிகத்திற்காக விண்ணப்பிக்க எனக்கு அதிகாரம் உள்ளது, விவரங்கள் சரியானவை.** ஐக் குறிக்கவும்.
2. விதிமுறைகளை ஏற்பதைக் குறிக்கவும்.
3. காட்டப்பட்டால் **ரோபோ சோதனையை** முடிக்கவும்.
4. <span class="ui">விண்ணப்பத்தை அனுப்பு</span> ஐத் தேர்ந்தெடுக்கவும்.

## 2. உங்கள் மின்னஞ்சலை உறுதிப்படுத்துங்கள்

GPOS **உங்கள் மின்னஞ்சலைச் சரிபார்க்கவும்** என்று காட்டும். நாங்கள் அனுப்பிய இணைப்பை **24 மணி நேரத்துக்குள்** திறக்கவும்.
அதன் பிறகே விண்ணப்பம் மதிப்பாய்வு செய்யப்படும். உறுதிப்படுத்தப்படாத விண்ணப்பங்கள் 7 நாட்களுக்குப் பின் நீக்கப்படும்.
ஒரு மின்னஞ்சல் முகவரிக்கு ஒரே நேரத்தில் **ஒரு திறந்த விண்ணப்பம்** மட்டுமே.

## 3. உங்கள் விண்ணப்பத்தைக் கண்காணியுங்கள்

உள்நுழைவுப் பக்கத்தில் **எனது விண்ணப்பத்தைச் சரிபார்** ஐத் தேர்ந்தெடுத்து, விண்ணப்பித்த மின்னஞ்சலை உள்ளிட்டு
<span class="ui">எனக்கு இணைப்பை அனுப்பு</span> ஐத் தேர்ந்தெடுக்கவும். இணைப்பு (24 மணி நேரம்) **உங்கள் விண்ணப்பம்** ஐ நிலை மற்றும் வரலாற்றுடன் திறக்கும்.

| நிலை | பொருள் |
|------|--------|
| **மின்னஞ்சல் உறுதிப்படுத்தப்படவில்லை** | நாங்கள் அனுப்பிய இணைப்பைத் திறக்கவும். |
| **மதிப்பாய்வுக்காகக் காத்திருக்கிறது** | ஒருவர் மதிப்பாய்வு செய்கிறார்; மின்னஞ்சல் அனுப்புவோம். |
| **மேலும் தகவல் தேவை** | கேள்வி கேட்டுள்ளோம் — கீழே பாருங்கள். |
| **அங்கீகரிக்கப்பட்டது** | உங்கள் வணிகம் தயார்; கடவுச்சொல்லைத் தேர்ந்தெடுக்க இணைப்பை அனுப்பினோம். |
| **அங்கீகரிக்கப்படவில்லை** | காரணம் வரலாற்றில் உள்ளது. |
| **திரும்பப் பெறப்பட்டது** | நீங்கள் விண்ணப்பத்தைத் திரும்பப் பெற்றீர்கள். |

**தகவல் தேவைப்படும்போது:** இணைப்பைத் (7 நாட்கள்) திறந்து **உங்கள் பதில்** ஐ எழுதவும், தேவைப்பட்டால் **எனது விவரங்களையும்
திருத்து** ஐக் குறித்துத் திருத்தவும், பின்னர் <span class="ui">பதிலை அனுப்பு</span>. மருந்தகங்கள், மருத்துவமனைகள், கிளினிக்குகள்,
மருத்துவப் பொருட்கள் போன்ற ஒழுங்குபடுத்தப்பட்ட வணிகங்களிடம் உரிம விவரங்கள் கேட்கப்படலாம்.

மனம் மாறிவிட்டதா? <span class="ui">விண்ணப்பத்தைத் திரும்பப் பெறு</span> ஐத் தேர்ந்தெடுக்கவும். பின்னர் மீண்டும் விண்ணப்பிக்கலாம்.

## 4. அங்கீகரிக்கப்பட்டது — உங்கள் கணக்கைச் செயல்படுத்துங்கள்

அங்கீகரிக்கப்பட்டதும் முதன்மைக் கிளையுடன் உங்கள் வணிகம் உருவாக்கப்பட்டு **நீங்கள் அதன் உரிமையாளர்** ஆவீர்கள். இணைய
விண்ணப்பங்களுக்கு ஒப்புக்கொள்ளப்பட்ட திட்டம் ஒதுக்கப்படும் ([திட்டங்கள் மற்றும் அம்சங்கள்](/ta/getting-started/plans/)).
**கடவுச்சொல்லைத் தேர்ந்தெடுக்க** இணைப்பு (**7 நாட்கள்** செல்லுபடியாகும்) மின்னஞ்சலில் அனுப்பப்படும்; உங்கள் விண்ணப்பப் பக்கம்
**உங்கள் வணிகக் குறியீடு** ஐக் காட்டும்.

1. மின்னஞ்சல் இணைப்பைத் திறந்து கடவுச்சொல்லைத் தேர்ந்தெடுக்கவும் (குறைந்தது 12 எழுத்துகள்).
2. [app.gpos.lk](https://app.gpos.lk) இல் வணிகக் குறியீடு, மின்னஞ்சல் மற்றும் புதிய கடவுச்சொல்லுடன் உள்நுழையவும்.
3. சேவை விதிமுறைகளை ஏற்று, கேட்கப்பட்டால் [இரு-படி உள்நுழைவு](/ta/getting-started/two-step-sign-in/) ஐ அமைக்கவும்.
4. **[விரைவுத் தொடக்கம்](/ta/quick-start/)** உடன் தொடருங்கள்.

:::tip[இணைப்பு காலாவதியானதா?]
7 நாட்களுக்குள் திறக்கவில்லையெனில், புதிய இணைப்புக்கு GPOS Support ஐத் தொடர்பு கொள்ளுங்கள்.
:::
