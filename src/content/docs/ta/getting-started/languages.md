GPOS — back office, till, இந்த guide — **English**, **සිංහල**, **தமிழ்** ஆகிய மொழிகளில் உள்ளது.

## எந்த மொழி பயன்படுத்தப்படும்?

1. **உங்கள் சொந்தத் தேர்வு** — sign-in page இலும் app இலும் உள்ள language switch.
2. **உங்கள் employee setting** — administrator **Employees → Edit** இல் ஒவ்வொரு employee இன் **Language** ஐ set
   செய்யலாம். *Business default* என்றால் business இன் மொழியே பயன்படும்.
3. **Business default** — owner **Settings → Regional settings → Default language** இல் set செய்வார்.

## Products இன் சிங்களம் மற்றும் தமிழ் பெயர்கள்

Customers receipts ஐத் தங்கள் மொழியில் படிக்க விரும்புவார்கள். சிங்களம் மற்றும் தமிழ் பெயர்களை add செய்ய:

1. **Settings → Products and prices** க்குச் சென்று **Use Sinhala/Tamil product names** ஐ tick செய்யுங்கள்.
2. <span class="ui">Save settings</span> ஐத் தேர்ந்தெடுங்கள்.
3. இப்போது ஒவ்வொரு product இலும் **Sinhala name** மற்றும் **Tamil name** fields உள்ளன (கட்டாயமில்லை). Import
   spreadsheet இல் `name_si` மற்றும் `name_ta` columns ஐப் பயன்படுத்துங்கள்.

இந்தப் பெயர்கள் நிரப்பப்பட்டிருந்தால் till மற்றும் receipts அவற்றைப் பயன்படுத்தும். Payment methods, cash in/out
reasons போன்ற lists க்கும் சிங்களம் மற்றும் தமிழ் பெயர்களைப் போடலாம்.

## இந்த guide

எந்த page இன் மேலும் உள்ள language menu மூலம் மொழியை மாற்றுங்கள். Buttons மற்றும் menus இன் பெயர்கள் இங்கே
English இல் உள்ளன — app இன் English மொழியில் தெரிவது போலவே. App ஐத் தமிழில் பயன்படுத்தினால், அதே buttons அதே
இடங்களில் இருக்கும்.
