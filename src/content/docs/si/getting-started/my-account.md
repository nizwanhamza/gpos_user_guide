ඔබේම sign-in විස්තර — password එක, **two-step sign-in** සහ POS PIN එක — manage කරන්න menu එකේ පහළ
<span class="ui">My account</span> තෝරන්න.

## Password එක වෙනස් කරන්න

1. ඔබේ **Current password** එක type කරන්න.
2. **New password** එකක් (අවම අකුරු 12) type කර **Confirm new password** හි ආයෙත් type කරන්න.
3. <span class="ui">Change password</span> තෝරන්න.

ඔබේ අනිත් හැම session එකකින්ම sign out වෙනවා — උදා. වෙනත් computer එකක තවම sign in වෙලා හිටියා නම්.

## Two-step sign-in

අමතර ආරක්ෂාවට authenticator app එකක code එකක් on කරන්න, recovery codes කීයක් ඉතුරුද බලන්න, නැත්නම් off
කරන්න. පියවරෙන් පියවර: [Two-step sign-in](/si/getting-started/two-step-sign-in/).

## POS PIN එක set කිරීම හෝ වෙනස් කිරීම

**POS PIN** එක ඔබේ branch එකේ tills unlock කරන ඉලක්කම් 6ක number එකක් — till එක offline වුණත් වැඩ කරනවා.
Back office එකට sign in වෙන්න එය භාවිතා කරන්න **බැහැ**.

1. <span class="ui">Set POS PIN</span> (හෝ <span class="ui">Change POS PIN</span>) තෝරන්න.
2. ඔබමයි කියලා confirm කරන්න ඔබේ දැනට තියෙන **password** එක type කරන්න.
3. ඉලක්කම් 6ක **New PIN** එකක් type කර **Repeat the PIN** හි ආයෙත් type කරන්න.
4. Save කරන්න. Tills වලට අලුත් PIN එක ලැබෙන්නේ ඒවායේ **ඊළඟ sync** එකේදී (online නම් සාමාන්‍යයෙන් විනාඩියක් ඇතුළත).

PIN rules:

- හරියටම **ඉලක්කම් 6**;
- එකම ඉලක්කම නැවත නැවත නොවෙන්න (`111111`);
- පිළිවෙළක් නොවෙන්න (`123456` හෝ `654321`).

:::caution[PIN එක ඔබ ළඟම තියාගන්න]
Till එකේ කරන හැම දෙයක්ම — sales, discounts, refunds, ගත්ත cash සහ approvals — record වෙන්නේ till එක unlock කළ
PIN එකේ අයිතිකරුගේ නමින්.
:::
