:::note[Depends on your plan]
**Stock counts** is a plan feature (it needs **Stock control**). Without it, the **Counts** tab does not appear. See [Plans and features](/getting-started/plans/).
:::

A **stock count** compares what is on the shelves with what GPOS expects, then posts the
differences as adjustments. Each item keeps the system level **at the moment it was counted**, so
the **tills can keep selling during a count**. Items not counted are left as they are.

## Start a count

1. Go to **Inventory → Counts** → <span class="ui">New count</span>.
2. Choose the **Store**.
3. **What to count** — *Everything in the store*, or a category (sub-categories are included).
4. Tick **Blind count** if counters should **not** see the system quantity — this gives more
   honest counts.
5. Select <span class="ui">Start count</span>.

## Count

The count shows *… of … items counted*.

- **Scan or type a barcode / SKU** and select <span class="ui">Find</span> to jump to an item, then
  enter the quantity counted. A barcode not in this count is reported.
- Use the filters: **All**, **Not counted**, **Counted**, **Differences**.

When the counting is done, select <span class="ui">Finish counting</span>. The count goes **In
review**. Select <span class="ui">Count more</span> to go back.

## Review and post

In review you see for each item the **System** quantity, **Counted** and the **Difference**, and
the **Difference in value**. Recount anything that looks wrong.

Select <span class="ui">Post differences</span>. Each counted item is adjusted by its difference.
**This cannot be undone.**

Not needed after all? <span class="ui">Cancel count</span>.

Statuses: *Counting* → *In review* → *Posted* (or *Cancelled*).
