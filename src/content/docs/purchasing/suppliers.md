---

Go to **Purchasing → Suppliers** → <span class="ui">Add supplier</span>.

| Field | Example |
|-------|---------|
| **Name** | Ceylon Tea Distributors (Pvt) Ltd |
| **Contact person** | Mr. Perera |
| **Phone**, **Email** | |
| **Tax registration no.** | Their VAT number |
| **Payment terms** | 30 days credit |
| **Active** | Untick when you stop buying from them |

Suppliers are used on [purchase orders](/purchasing/purchase-orders/), when
[receiving goods](/purchasing/receiving-goods/) and for [returns](/purchasing/supplier-returns/).
The **Purchases** report shows what you bought per supplier.
