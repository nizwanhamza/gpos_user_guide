**Payment methods** **Settings** இல் உள்ளன. Customer செலுத்தும்போது cashier க்குத் தெரியும் buttons இவை.

Card, QR, bank-transfer payments **உங்கள் bank இன் terminal அல்லது app** இல் எடுக்கப்படும். GPOS அவற்றை cashier type செய்யும்
reference உடன் **record செய்யும் மட்டுமே**. Card numbers ஒருபோதும் save செய்யப்படாது. **Cash எப்போதும் உண்டு.**

## Ready-made methods

| Method | Type | Reference தேவையா |
|--------|------|-------------------|
| Cash | Cash | இல்லை |
| Card | Card (terminal) | ஆம் |
| QR payment | QR payment | ஆம் |
| Bank transfer | Bank transfer | ஆம் |

## Payment method ஐ add செய்யுங்கள்

1. <span class="ui">Add payment method</span> ஐத் தேர்ந்தெடுங்கள்.
2. **Name**, விரும்பினால் **Name in Sinhala** மற்றும் **Name in Tamil** ஐ உள்ளிடுங்கள்.
3. **Type** ஐத் தேர்ந்தெடுங்கள்: Cash, Card (terminal), QR payment, Bank transfer அல்லது Other. Type ஐப் பின்னர் மாற்ற முடியாது.
4. ஒவ்வொரு payment க்கும் reference வேண்டுமானால் **The cashier must type the approval code or reference** ஐ tick செய்யுங்கள்
   (card மற்றும் QR க்குப் பரிந்துரைக்கப்படுகிறது).
5. **Order** ஐ set செய்யுங்கள் — குறைந்த எண்கள் முதலில் காட்டப்படும்.
6. Save செய்யுங்கள்.

உதாரணங்கள்: *LankaQR*, *Gift voucher* (Other), *Amex terminal* (Card).

## Switch off, edit அல்லது delete

- <span class="ui">Switch off</span> செய்தால் tills இல் method தெரியாது. <span class="ui">Switch on</span> செய்தால் மீண்டும் வரும்.
- <span class="ui">Edit</span> மூலம் பெயர், reference rule அல்லது order ஐ மாற்றலாம்.
- <span class="ui">Delete</span> ஒருபோதும் பயன்படுத்தாத method க்கு மட்டுமே முடியும். பயன்படுத்திய methods ஐ switch off மட்டுமே
  செய்யலாம்; பழைய sales அப்போது இருந்த பெயரையே வைத்திருக்கும்.

Tills க்கு மாற்றங்கள் அடுத்த sync இல் கிடைக்கும்.
