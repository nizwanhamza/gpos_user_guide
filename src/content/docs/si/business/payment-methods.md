**Payment methods** තියෙන්නේ **Settings** හි. Customer ගෙවනකොට cashier ට පෙනෙන buttons මේවා.

Card, QR සහ bank-transfer payments ගන්නේ **ඔබේ bank එකේ terminal එකෙන් හෝ app එකෙන්**. GPOS ඒවා cashier type කරන
reference එකත් එක්ක **record කරනවා විතරයි**. Card numbers කවදාවත් save කරන්නේ නැහැ. **Cash හැම විටම තියෙනවා.**

## Payment method එකක් add කරන්න

1. <span class="ui">Add payment method</span> තෝරන්න.
2. **Name** එක, සහ අවශ්‍ය නම් **Name in Sinhala** සහ **Name in Tamil** දාන්න.
3. **Type** එක තෝරන්න: Cash, Card (terminal), QR payment, Bank transfer හෝ Other. Type එක පස්සේ වෙනස් කරන්න බැහැ.
4. හැම payment එකකටම reference එකක් ඕන නම් **The cashier must type the approval code or reference** tick කරන්න
   (card සහ QR වලට නිර්දේශ කරනවා).
5. **Order** එක set කරන්න — අඩු numbers මුලින් පෙන්නනවා.
6. Save කරන්න.

උදාහරණ: *LankaQR*, *Gift voucher* (Other), *Amex terminal* (Card).

## Switch off, edit හෝ delete

- <span class="ui">Switch off</span> කළාම tills වල method එක පෙනෙන්නේ නැහැ. <span class="ui">Switch on</span> කළාම ආයෙත් එනවා.
- <span class="ui">Edit</span> එකෙන් නම, reference rule එක හෝ order එක වෙනස් කරන්න පුළුවන්.
- <span class="ui">Delete</span> කරන්න පුළුවන් කවදාවත් භාවිතා නොකළ method එකක් විතරයි. භාවිතා කළ methods switch off කරන්න
  විතරයි පුළුවන්; පරණ sales වල ඒ වෙලාවේ තිබුණු නම එහෙමම තියෙනවා.

Tills වලට වෙනස්කම් ලැබෙන්නේ ඊළඟ sync එකේදී.
