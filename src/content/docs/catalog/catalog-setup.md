**Catalog setup** has four tabs: **Categories**, **Brands**, **Units** and **Taxes**. Set these up
before adding many products — or let the [import](/catalog/import-export/) create categories and
brands for you.

## Categories

Categories group products on reports and stock counts. They can go **up to 3 levels** deep, for
example *Beverages › Soft drinks › Carbonated*.

1. Select <span class="ui">New category</span>.
2. Enter the **Name**.
3. Choose a **Parent category**, or *None (top level)*.
4. Set the **Sort order** — lower numbers are listed first.
5. Save.

Select <span class="ui">Add subcategory</span> next to a category to add one under it. To
deactivate a category, deactivate its subcategories first.

## Brands

Brands appear on products and in the *Sales by brand* report. Select
<span class="ui">New brand</span>, enter the name, and save.

## Units

A product's **unit** decides how it is priced and counted. Standard units are provided for every
business:

| Unit | Code | Measures |
|------|------|----------|
| Piece | `pcs` | Count |
| Pack | `pack` | Count |
| Kilogram | `kg` | Weight |
| Gram | `g` | Weight |
| Litre | `l` | Volume |
| Millilitre | `ml` | Volume |
| Metre | `m` | Length |

To add your own — for example *dozen* or *bundle*:

1. Select <span class="ui">New unit</span>.
2. Enter a short, lowercase **Code** (for example `doz`) — it cannot be changed later — and a
   **Name**.
3. Choose what it **Measures**: Count, Weight, Volume or Length.
4. Set **Decimals** — how many decimal places quantities may have, for example `3` for 1.250 kg.
5. Save.
