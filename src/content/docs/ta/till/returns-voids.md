:::note[உங்கள் plan ஐப் பொறுத்தது]
**Returns** மற்றும் **Voids** இரண்டு தனி plan features. ஒன்று இல்லாவிட்டால் till இல் **Sales** (F9) இல் அதன் button தெரியாது.
[Plans and features](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

| | **Void** | **Return** |
|-|----------|-----------|
| என்ன | **முழு** sale ஐயும் cancel செய்யும் | Items இல் **சிலவற்றை அல்லது அனைத்தையும்** திரும்பப் பெறும் |
| எப்போது | Sale செய்த **அதே shift** இல் | பின்னர், business இன் **return window** க்குள் (default 30 நாட்கள்) |
| Refund | செலுத்திய வழியிலேயே | நீங்கள் தேர்ந்தெடுக்கும் method க்கு |

இரண்டுக்கும் **open shift** தேவை (refunds அதன் drawer இலிருந்து வரும்), மேலும் உங்கள் role அனுமதிக்காவிட்டால் **manager இன் approval**.

## Sale ஐக் கண்டுபிடியுங்கள்

1. **Sales on this till** ஐ open செய்ய <span class="ui">Sales</span> (**F9**) ஐத் தேர்ந்தெடுங்கள். இங்கே receipt ஐ reprint செய்யலாம்,
   அல்லது முழு page invoice க்கு <span class="ui">Print A4</span> செய்யலாம்.
2. **Search receipt number**, அல்லது list இலிருந்து sale ஐத் தேர்ந்தெடுங்கள்.
3. **வேறு till இன்** sale ஆ? Receipt number ஐ type செய்து <span class="ui">Find … (another till)</span> ஐத் தேர்ந்தெடுங்கள் — இதற்கு internet தேவை.

## Items ஐ return செய்யுங்கள்

1. Sale இல் <span class="ui">Return</span> ஐத் தேர்ந்தெடுங்கள் (பிறகு <span class="ui">Return items</span>).
2. ஒவ்வொரு line க்கும் **Quantity to return** ஐ உள்ளிடுங்கள் (அல்லது <span class="ui">All</span>). என்ன விற்கப்பட்டது, ஏற்கனவே
   என்ன return ஆனது என்று screen காட்டும்.
3. **Reason** ஐத் தேர்ந்தெடுங்கள் — *Faulty*, *Wrong item*, *Changed mind* அல்லது உங்கள் சொந்தம்.
4. Item ஐ மீண்டும் விற்க முடிந்தால் **Back to stock (resellable)** ஐ tick செய்யுங்கள். Damaged goods க்கு untick ஆகவே விடுங்கள் —
   அவை restock செய்யப்படாதவை என record ஆகும்.
5. **Refund to** ஐத் தேர்ந்தெடுங்கள் — உதா. *Cash* — card, QR அல்லது bank refunds க்கு terminal அல்லது app இலிருந்து **Refund
   reference** ஐ type செய்யுங்கள். Cash அல்லாத method அதன் மூலம் செலுத்தியது வரை மட்டுமே திரும்பப் பெறலாம்; மீதியை cash ஆக refund செய்யுங்கள்.
6. <span class="ui">Refund {amount}</span> ஐத் தேர்ந்தெடுத்து, கேட்டால் manager இன் approval ஐப் பெறுங்கள்.

Original receipt number உடன் **RETURN / REFUND** receipt print ஆகும்.

## Sale ஐ void செய்யுங்கள்

1. Sale இல் <span class="ui">Void</span> ஐத் தேர்ந்தெடுங்கள் (பிறகு <span class="ui">Void sale</span>).
2. **Reason** ஐத் தேர்ந்தெடுங்கள். அது **செலுத்திய வழியிலேயே எப்படி refund ஆகும்** என்று screen காட்டும்.
3. <span class="ui">Void the sale</span> ஐத் தேர்ந்தெடுத்து, கேட்டால் approval ஐப் பெறுங்கள்.

**VOID** receipt print ஆகும்.

## தெரிந்துகொள்ள வேண்டியவை

- Offline ஆக இருக்கும்போது till **இந்த till இல்** செய்த returns ஐ மட்டுமே அறியும்.
- *This sale is older than the business's return window* — return window கடந்துவிட்டது.
- Returns மற்றும் voids **Sales** இல் (*Returned*, *Partly returned*, *Voided*) மற்றும் **Refunds & voids** report இல் தெரியும்.
