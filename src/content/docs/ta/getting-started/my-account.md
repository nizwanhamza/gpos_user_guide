உங்கள் சொந்த sign-in விவரங்களை — password, **two-step sign-in**, POS PIN — manage செய்ய menu இன் கீழே
<span class="ui">My account</span> ஐத் தேர்ந்தெடுங்கள்.

## Password ஐ மாற்றுங்கள்

1. உங்கள் **Current password** ஐ type செய்யுங்கள்.
2. **New password** (குறைந்தது 12 எழுத்துகள்) ஐ type செய்து **Confirm new password** இல் மீண்டும் type செய்யுங்கள்.
3. <span class="ui">Change password</span> ஐத் தேர்ந்தெடுங்கள்.

உங்கள் மற்ற எல்லா sessions இலிருந்தும் sign out ஆகும் — உதா. வேறு computer இல் இன்னும் sign in ஆகியிருந்தால்.

## Two-step sign-in

கூடுதல் பாதுகாப்புக்கு authenticator app code ஐ on செய்யுங்கள், எத்தனை recovery codes மீதம் உள்ளன என்று பாருங்கள்,
அல்லது off செய்யுங்கள். படிப்படியாக: [Two-step sign-in](/ta/getting-started/two-step-sign-in/).

## POS PIN ஐ set செய்தல் அல்லது மாற்றுதல்

**POS PIN** என்பது உங்கள் branch இன் tills ஐ unlock செய்யும் 6 இலக்க எண் — till offline ஆக இருந்தாலும் வேலை செய்யும்.
Back office இல் sign in செய்ய இதைப் பயன்படுத்த **முடியாது**.

1. <span class="ui">Set POS PIN</span> (அல்லது <span class="ui">Change POS PIN</span>) ஐத் தேர்ந்தெடுங்கள்.
2. நீங்கள்தான் என்று உறுதிசெய்ய உங்கள் தற்போதைய **password** ஐ type செய்யுங்கள்.
3. 6 இலக்க **New PIN** ஐ type செய்து **Repeat the PIN** இல் மீண்டும் type செய்யுங்கள்.
4. Save செய்யுங்கள். Tills க்கு புதிய PIN அவற்றின் **அடுத்த sync** இல் கிடைக்கும் (online ஆக இருந்தால் பொதுவாக ஒரு நிமிடத்துக்குள்).

PIN rules:

- சரியாக **6 இலக்கங்கள்**;
- ஒரே இலக்கம் திரும்பத் திரும்ப இருக்கக்கூடாது (`111111`);
- வரிசையாக இருக்கக்கூடாது (`123456` அல்லது `654321`).

:::caution[PIN ஐ உங்களிடமே வைத்திருங்கள்]
Till இல் செய்யப்படும் அனைத்தும் — sales, discounts, refunds, எடுத்த cash, approvals — till ஐ unlock செய்த PIN இன்
உரிமையாளர் பெயரிலேயே record ஆகும்.
:::
