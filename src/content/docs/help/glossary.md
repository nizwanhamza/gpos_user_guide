title: Glossary

| Word | Meaning |
|------|---------|
| **Added at till** | A product a cashier added at the till for an unknown barcode; complete its details in Products. |
| **Application** | A request to open a GPOS account for your business, made at app.gpos.lk/register and reviewed by GPOS. |
| **Back office** | The GPOS web admin for owners and managers. |
| **Business code** | The short code of your business, used with your e-mail to sign in. |
| **Branch** | A shop or outlet. |
| **Register** | A checkout counter in a branch. Each has one till. |
| **Till** | The device and screen used to sell, paired to a register. Also called POS. |
| **Store / warehouse** | A place where stock is kept. Every branch has a default one. |
| **Shift** | A period of selling on one till, from opening (with a float) to closing (with a count). Named after who opened it and when, e.g. `Shift-Chamari-20261027-8.00am`. |
| **Float** | The cash in the drawer when a shift opens, for giving change. |
| **Cash in / cash out** | Money put in or taken out of the drawer that is not a sale or refund. |
| **Blind close** | Counting the drawer before seeing the expected amount. |
| **X report** | A mid-shift summary; the shift stays open. |
| **Z report** | The end-of-shift summary after closing. |
| **Reconciled** | A closed shift for which the back office has every record from the till. |
| **POS PIN** | A 6-digit number to unlock the till. |
| **Two-step sign-in** | Signing in to the back office with your password plus a code from an authenticator app. |
| **Authenticator app** | A phone app (Microsoft Authenticator, Google Authenticator…) that shows a new 6-digit code every 30 seconds. |
| **Recovery code** | One of 10 single-use codes for two-step sign-in when you do not have your phone. |
| **PDPA** | Sri Lanka's Personal Data Protection Act. Customers can ask for a copy of their data or for it to be erased. |
| **Receipt number** | `BRANCH-REGISTER-000123`, numbered per till; a replacement till adds `.2`, `.3`… |
| **SKU** | Your own code for a product variant. |
| **Variant** | One sellable version of a product (size, colour). |
| **Pack barcode** | A barcode for several units at once, written `code:quantity`. |
| **Tax group** | What a product is given; combines one or more tax rates. |
| **Quick-pick** | A product button on the till for items without barcodes. |
| **Opening stock** | The quantities you start with. |
| **Adjustment / write-off** | A stock correction / a stock loss, with a reason. |
| **Stock count** | Counting the shelves and posting the differences. |
| **Transfer** | Moving stock from one store to another. |
| **Batch / expiry** | A received lot of an item with its expiry date. |
| **Reorder level** | The quantity at which an item counts as low stock. |
| **Average cost** | The running average purchase cost of an item in a store. |
| **PO** | Purchase order (numbered `PO-…`). |
| **Go Green** | Finishing a sale without printing a receipt. |
| **GRN** | Goods received note — a booked delivery (numbered `GRN-…`). |
| **Void** | Cancelling a whole sale in the same shift. |
| **Return** | Giving back some or all items of a sale, with a refund. |
| **Sync** | The till sending its work to the back office and receiving updates. |
| **Sync issue** | Something from a till the back office could not accept as recorded; an administrator decides. |
| **Robot check** | A quick check on public pages (sign-in, passwords, applications) that you are a person, not a bot. |
| **Support session** | Your service provider helping you inside your account; always shown and recorded. |
| **Gocart.lk** | An online marketplace where you can open your own shop from GPOS (**Sell online**). |
| **Sold online** | A stock movement for an item ordered on Gocart.lk. |
