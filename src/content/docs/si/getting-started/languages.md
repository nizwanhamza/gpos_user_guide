GPOS — back office එක, till එක සහ මේ guide එක — **English**, **සිංහල** සහ **தமிழ்** භාෂාවලින් තියෙනවා.

## පාවිච්චි වෙන්නේ කුමන භාෂාවද?

1. **ඔබේම තේරීම** — sign-in page එකේ සහ app එකේ තියෙන language switch එක.
2. **ඔබේ employee setting එක** — administrator කෙනෙකුට **Employees → Edit** හි හැම employee කෙනෙකුගේම
   **Language** එක set කරන්න පුළුවන්. *Business default* තේරුවොත් business එකේ භාෂාවම ගන්නවා.
3. **Business default එක** — owner විසින් **Settings → Regional settings → Default language** හි set කරනවා.

## Products වල සිංහල සහ දෙමළ නම්

Customers ට receipts තමන්ගේ භාෂාවෙන් කියවන්න කැමතියි. සිංහල සහ දෙමළ නම් add කරන්න:

1. **Settings → Products and prices** වෙත ගිහින් **Use Sinhala/Tamil product names** tick කරන්න.
2. <span class="ui">Save settings</span> තෝරන්න.
3. දැන් හැම product එකකම **Sinhala name** සහ **Tamil name** fields තියෙනවා (අනිවාර්ය නැහැ). Import spreadsheet
   එකේ `name_si` සහ `name_ta` columns භාවිතා කරන්න.

මේ නම් පුරවලා තියෙනවා නම් till එක සහ receipts ඒවා භාවිතා කරනවා. Payment methods, cash in/out reasons වගේ
lists වලත් සිංහල සහ දෙමළ නම් දාන්න පුළුවන්.

## මේ guide එක

ඕනෑම page එකක උඩ තියෙන language menu එකෙන් භාෂාව මාරු කරන්න. Buttons සහ menus වල නම් මෙහි English
වලින් තියෙනවා — app එකේ English භාෂාවේ පෙනෙන විදිහටම. App එක සිංහලෙන් භාවිතා කරනවා නම්, ඒ buttons ම
එකම තැන්වල තියෙනවා.
