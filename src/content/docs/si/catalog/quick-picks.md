**Quick-pick buttons** කියන්නේ till එකේ main screen එකේ තියෙන product buttons — **barcodes නැති** items වලට ගොඩක්
හොඳයි, උදා. loose එළවළු, bakery items හෝ tea cup එකක්. හැම **branch** එකකටම buttons **40ක්** දක්වා තමන්ගේම set එකක් තියෙනවා.

## Buttons setup කරන්න

1. **Branches** වෙත ගිහින් branch එකේ <span class="ui">Quick-pick buttons</span> තෝරන්න.
2. දකුණු පැත්තේ **Search products** කර ඒවා add කරන්න. **එක** variant එකක් තියෙන product එකක් වහාම add වෙනවා; variants
   කිහිපයක් (sizes, colours…) තියෙන එකකට GPOS **Which …?** කියලා අහනවා — variant එක තෝරන්න, නැත්නම්
   <span class="ui">Back</span> තෝරන්න. හැම button එකක්ම variant එකක්.
3. වැඩියෙන්ම භාවිතා කරන items මුලට දාන්න <span class="ui">Move up</span> / <span class="ui">Move down</span>, එකක් අයින්
   කරන්න <span class="ui">Remove</span> භාවිතා කරන්න.
4. Save කරන්න.

Tills වලට වෙනස්කම් ලැබෙන්නේ ඊළඟ sync එකේදී.
