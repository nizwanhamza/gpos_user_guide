:::note[உங்கள் plan ஐப் பொறுத்தது]
**Purchase orders** ஒரு plan feature (அதற்கு **Suppliers and goods received** தேவை). அது இல்லாவிட்டால் **Purchase orders** tab தெரியாது —
order இல்லாமலும் goods ஐ receive செய்யலாம். [Plans and features](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

**Purchase order (PO)** என்பது supplier இடம் நீங்கள் order செய்வது. POs ஐப் பயன்படுத்துவது கட்டாயமில்லை —
[order இல்லாமல் goods ஐ receive](/ta/purchasing/receiving-goods/) செய்யவும் முடியும்.

## Purchase order ஐ உருவாக்குங்கள்

1. **Purchasing → Purchase orders** → <span class="ui">New purchase order</span> க்குச் செல்லுங்கள்.
2. **Supplier** மற்றும் goods செல்லும் **Store** ஐத் தேர்ந்தெடுங்கள்.
3. **Add an item**: name அல்லது SKU ஐ search செய்யுங்கள். ஒவ்வொரு line க்கும் set செய்யுங்கள்:
   - **Unit** — product இன் unit, அல்லது **pack** (உதா. 24 இன் case — **pack size** ஐ உள்ளிடுங்கள்);
   - **Quantity** மற்றும் **Cost per unit**.
4. விரும்பினால் **Expected on** மற்றும் **Note** ஐ உள்ளிடுங்கள்.
5. <span class="ui">Save draft</span> ஐத் தேர்ந்தெடுங்கள்.

## அனுப்புங்கள்

Order ஐ open செய்து supplier க்கு அனுப்ப <span class="ui">Print / save as PDF</span> ஐத் தேர்ந்தெடுங்கள், பிறகு <span class="ui">Mark as ordered</span>.

A4 இல் order மட்டுமே print ஆகும் — menus அல்லது buttons இல்லை:

- உங்கள் **letterhead** — logo (இருந்தால்), business பெயர், address, phone, e-mail, tax registration no.;
- **Purchase order** மற்றும் அதன் number, **Order date**, **Expected delivery**, **Status**;
- **Supplier** (அவர்களின் tax no. மற்றும் payment terms உடன்) மற்றும் **Deliver to** இடம்;
- quantity, cost per unit, line totals உடன் items, **Total**, உங்கள் **Note**;
- கீழே *Printed … by …*.

E-mail செய்ய print window இல் **Save as PDF** ஐத் தேர்ந்தெடுங்கள். File பெயர் உங்களுக்குப் பரிந்துரைக்கப்படும், உதா. *Purchase order PO-000012*.

## Statuses

| Status | அர்த்தம் |
|--------|-----------|
| **Draft** | தயாராகிறது; இன்னும் edit செய்யலாம். |
| **Ordered** | Supplier க்கு அனுப்பப்பட்டது. |
| **Partly received** | சில goods வந்துவிட்டன. |
| **Received** | எல்லாம் வந்துவிட்டது, அல்லது order close செய்யப்பட்டது. |
| **Cancelled** | தொடராது. |

## Goods வரும்போது

Order ஐ open செய்து <span class="ui">Receive goods</span> ஐத் தேர்ந்தெடுங்கள் — [Receiving goods](/ta/purchasing/receiving-goods/) ஐப் பாருங்கள்.

- Supplier மீதியை அனுப்பமாட்டாரா? <span class="ui">Close (nothing more expected)</span>.
- Order தேவையில்லையா? <span class="ui">Cancel order</span>.

**Open purchase orders** report இன்னும் வர வேண்டிய goods ஐப் பட்டியலிடும்.
