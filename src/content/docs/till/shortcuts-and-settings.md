## Keyboard shortcuts

The same list is on the till: the **keyboard button** at the top right, or **Ctrl + K**.

### Selling

| Key | Action |
|-----|--------|
| **F1** | Edit the last item added: quantity, variant, discount |
| **F2** | Go to the scan box |
| **F3** | Customer for the sale (find by phone or name, or add a new one) |
| **F4** | Pay. Without a customer the till asks first: **F3** (or Enter) adds one, **F4** again pays without |
| **F5** | Print the last receipt again |
| **F6** | Put the sale on hold |
| **F7** | Sales on hold (resume or discard) |
| **F8** | Discount on the whole sale |
| **Num +** / **Num −** | One more / one less of the last item (number pad, while nothing is typed) |
| **Ctrl + Delete** | Clear the sale (asks first) |
| **↑ ↓**, **Enter** | Choose a search result (or a customer) and add it |

### Paying and after the sale

| Key | Action |
|-----|--------|
| **F4** or **Enter** | In the Pay window: complete the sale (or add the part payment) |
| **Enter** or **F5** | After the sale: print the receipt |
| **Esc** | After the sale: Go Green — no receipt |
| **Enter** | In the customer search, when nobody is found: add the number or name typed as a new customer |

### Shift, sales and the till

| Key | Action |
|-----|--------|
| **F9** | Sales: find a receipt, reprint it, print it on **A4**, return items or void |
| **F10** | Shift: cash in/out, X report (receipt printer or **A4**), close |
| **F11** | Full screen on / off |
| **F12** | Lock the till |
| **Ctrl + K** | The list of keys |
| **Esc** | Close the open window |

You can also just start typing or scanning — the till sends it to the scan box. Function keys
never reach the scan box, so they never clash with a barcode scanner.

### Browser shortcuts are switched off

So that a stray key cannot reload the page, print the screen or leave the till in the middle of a
sale, the till ignores the browser's own shortcuts — reload (F5, Ctrl + R), print (Ctrl + P), find,
zoom, back and forward, and the right-click menu outside text fields. Copy, paste, cut, undo and
select all still work in every field.

A few keys belong to the computer and cannot be switched off by any web page, such as
**Ctrl + W**, **Ctrl + T** and **Alt + F4**. Run the till as an
[installed app](/till/set-up-a-till/#install-it-as-an-app-recommended) in full screen to avoid them.

## Till settings

Open the sync panel (select the status bar) to find the till's own settings. They apply to **this
device** only.

### Receipt printing

- **Receipt paper** — *58 mm* or *80 mm* (80 mm by default).
- **Receipts** — tick **Print after each sale** to print automatically.

Receipts print through the browser to the printer installed on the device. Set the receipt printer
as the **default printer** and, in Chrome or Edge, turn off headers and footers in the print
dialog. For silent printing without a dialog, ask your IT support about Chrome's *kiosk printing*
option.

What is printed (name, header lines, footer, tax number) is set in
[Settings → Receipts](/business/settings/#receipts).

### Screen

- **Screen** (in the sync panel) — the till keeps the screen on while it is open, if the browser
  allows it.
- In the **top bar**: <span class="ui">Larger text</span> / <span class="ui">Normal text</span> for
  bigger buttons and prices, and <span class="ui">Full screen</span> /
  <span class="ui">Exit full screen</span>.

### Scan sounds

Turn the beep on scanning **On** or off.
