:::note[உங்கள் plan ஐப் பொறுத்தது]
**Stock counts** ஒரு plan feature (அதற்கு **Stock control** தேவை). அது இல்லாவிட்டால் **Counts** tab தெரியாது.
[Plans and features](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

**Stock count** shelves இல் உள்ளதை GPOS எதிர்பார்ப்பதுடன் ஒப்பிட்டு, differences ஐ adjustments ஆக post செய்யும். ஒவ்வொரு item உம்
**எண்ணிய நேரத்தில்** இருந்த system level ஐ வைத்திருக்கும், எனவே **count நடக்கும்போதும் tills தொடர்ந்து விற்கலாம்**. எண்ணாத items அப்படியே இருக்கும்.

## Count ஐத் தொடங்குங்கள்

1. **Inventory → Counts** → <span class="ui">New count</span> க்குச் செல்லுங்கள்.
2. **Store** ஐத் தேர்ந்தெடுங்கள்.
3. **What to count** — *Everything in the store*, அல்லது ஒரு category (sub-categories உட்பட).
4. எண்ணுபவர்களுக்கு system quantity **தெரியக்கூடாது** என்றால் **Blind count** ஐ tick செய்யுங்கள் — இது நேர்மையான counts ஐத் தரும்.
5. <span class="ui">Start count</span> ஐத் தேர்ந்தெடுங்கள்.

## எண்ணுங்கள்

Count *… of … items counted* எனக் காட்டும்.

- Item க்குச் செல்ல **barcode / SKU ஐ scan அல்லது type செய்து** <span class="ui">Find</span> ஐத் தேர்ந்தெடுத்து, எண்ணிய quantity ஐ
  உள்ளிடுங்கள். இந்த count இல் இல்லாத barcode report செய்யப்படும்.
- Filters ஐப் பயன்படுத்துங்கள்: **All**, **Not counted**, **Counted**, **Differences**.

எண்ணி முடிந்ததும் <span class="ui">Finish counting</span> ஐத் தேர்ந்தெடுங்கள். Count **In review** க்குச் செல்லும். திரும்பிச் செல்ல
<span class="ui">Count more</span> ஐத் தேர்ந்தெடுங்கள்.

## Review செய்து post செய்யுங்கள்

Review இல் ஒவ்வொரு item க்கும் **System** quantity, **Counted**, **Difference**, **Difference in value** தெரியும். தவறாகத் தெரிவதை
மீண்டும் எண்ணுங்கள்.

<span class="ui">Post differences</span> ஐத் தேர்ந்தெடுங்கள். எண்ணிய ஒவ்வொரு item உம் அதன் difference ஆல் adjust ஆகும். **இதை undo செய்ய முடியாது.**

தேவையில்லையா? <span class="ui">Cancel count</span>.

Statuses: *Counting* → *In review* → *Posted* (அல்லது *Cancelled*).
