:::note[ඔබේ plan එක අනුව වෙනස් වේ]
**Supplier returns** plan feature එකක් (ඒකට **Suppliers and goods received** ඕන). ඒක නැත්නම් **Returns** tab එක පෙනෙන්නේ නැහැ.
[Plans and features](/si/getting-started/plans/) බලන්න.
:::

ආපසු යවන goods **average cost එකට store එකේ stock එකෙන් අයින් වෙනවා**.

1. **Purchasing → Returns to suppliers** → <span class="ui">Return goods</span> වෙත යන්න.
2. **Supplier** සහ **Store** තෝරන්න.
3. Items සහ quantities add කරන්න.
4. **Reason** එකක් දාන්න (උදා. *Damaged in delivery*).
5. <span class="ui">Post return</span> තෝරන්න.

Return එක list එකේ ඒකේ **Value at cost** එක්ක පෙනෙනවා, stock ledger එකේ *Returned to supplier* ලෙස පෙනෙනවා.
