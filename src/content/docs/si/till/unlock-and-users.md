## Unlock කරන්න

1. **Who is using the till?** හි ඔබේ නම තෝරන්න.
2. Number pad එකෙන් (හෝ keyboard එකෙන්) **ඔබේ PIN එක type කරන්න**.

List එකේ ඔබ නැද්ද? List එකේ පෙන්නන්නේ **POS PIN එකක් තියෙන** සහ **මේ branch එකේ විකුණන්න අවසර තියෙන** අය. **Employees**
හි ඔබේ PIN එක set කරන්න කියලා administrator කෙනෙකුගෙන් ඉල්ලන්න, නැත්නම් [My account](/si/getting-started/my-account/) හි
තමන්ම set කරන්න. Till එකට ඒක ලැබෙන්නේ ඊළඟ sync එකේදී.

List එකේ *No cashiers yet* කියලා තියෙනවා නම්, මේ branch එකට තවම කාටවත් PIN එකක් නැහැ.

## වැරදි PIN

**වැරදි PINs 5ක්** දැම්මාම till එක ඒ කෙනාව විනාඩි 5කට lock out කරනවා, හැම පාරම ඉන්න ඕන කාලය වැඩි වෙනවා. කොච්චර වෙලා
ඉන්න ඕනද කියලා till එක පෙන්නනවා.

## Lock කිරීම සහ user මාරු කිරීම

- Counter එකෙන් යනකොට <span class="ui">Lock</span> තෝරන්න (හෝ **F12** ඔබන්න). Till එක ආයෙත් PIN එක අහනවා.
- සගයෙකුට භාර දෙන්න <span class="ui">Change user</span> තෝරන්න — till එක ආයෙත් *Who is using the till?* වෙත යනවා. සගයෙකුට
  lock screen එකේ <span class="ui">Someone else</span> තෝරන්නත් පුළුවන්.
- භාවිතා නොකර **විනාඩි 10කට පස්සේ till එක තනියම lock වෙනවා**.

Till එකේ කරන හැම දෙයක්ම — sales, discounts, refunds, cash out, approvals — record වෙන්නේ ඒක unlock කළ කෙනාගේ නමින්. Counter

## ඔබට කරන්න පුළුවන් දේ

Till එකේ පෙන්නන්නේ ඔබේ role එකෙන් ඉඩ දෙන දේ. උදාහරණයක් ලෙස, ඔබට විකුණන්න බැරි නම් *You can look up products, but not
sell on this till.* කියලා පෙන්නනවා. ඔබේ limit එකට වඩා වැඩි discounts, returns සහ voids වලට manager ගේ approval ඕන වෙන්න
පුළුවන් — [Discounts](/si/till/discounts/) බලන්න.
