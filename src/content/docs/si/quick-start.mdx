## පටන් ගන්න කලින්

මේවා සූදානම් කරගන්න:

- Back office එකට **Chrome හෝ Edge** තියෙන computer එකක්.
- **Till device** එක — Chrome හෝ Edge තියෙන counter computer, laptop හෝ tablet එකක්. USB හෝ Bluetooth
  barcode scanner එකක් සහ receipt printer එකක් (58 mm හෝ 80 mm) අනිවාර්ය නැහැ, නමුත් හොඳයි.
- Prices සමඟ ඔබේ **product list** එක (barcodes තියෙනවා නම් ඒවාත්). Spreadsheet එකක් නම් වඩාත් හොඳයි.
- ඔබ VAT registered නම් **VAT registration** විස්තර.
- GPOS භාවිතා කරන staff අයගේ **නම් සහ email addresses**.

## පියවර 0 — පළමු වරට sign in වීම

<Steps>

1. **[app.gpos.lk](https://app.gpos.lk)** හි back office එක open කරන්න.
2. ඔබේ **Business code**, **Email** සහ **Password** type කර <span class="ui">Sign in</span> තෝරන්න.
3. ඔබට පළමු password එකක් දී තිබුණා නම්, **අලුත් password එකක් තෝරන්න** කියලා අහනවා (අවම අකුරු 12 —
   මතක තියාගන්න ලේසි වාක්‍යයක් හොඳයි). දැන්ම එය කරන්න; පළමු password එක තාවකාලිකයි.
4. **Terms of service** (සහ privacy සහ data-processing terms) කියවා accept කරන්න: box එක tick කර
   <span class="ui">Accept and continue</span> තෝරන්න. මෙය අහන්නේ owner ගෙන් පමණයි.
5. GPOS **Set up two-step sign-in** කියලා ඇහුවොත්, phone එකේ authenticator app එකකින් QR code එක scan කර
   recovery codes ආරක්ෂිතව තබාගන්න — [Two-step sign-in](/si/getting-started/two-step-sign-in/) බලන්න.
   අනිවාර්ය නැති වුණත් owner ට එය දාගන්න කියලා අපි නිර්දේශ කරනවා.
6. අවශ්‍ය නම්: language switch එකෙන් භාෂාව තෝරන්න (English, සිංහල හෝ தமிழ்).

</Steps>

වැඩි විස්තර: [Signing in](/si/getting-started/signing-in/).

## පියවර 1 — Business details සහ receipt header

ඔබ කවුද කියලා GPOS ට කියන්න. මේ විස්තර receipts වල print වෙනවා.

<Steps>

1. **Settings** → **Business profile** වෙත යන්න.
2. ඔබේ **Phone**, **Contact email** සහ **Address** කොටස පුරවන්න.
3. **Regional settings** බලන්න: currency, time zone සහ staff අයට **Default language** එක.
4. **Receipts** දක්වා scroll කර, හැම receipt එකකම උඩින් print වෙන **Header lines** add කරන්න (lines 4ක්
   දක්වා — උදා. address එක සහ hotline එක) සහ *Thank you, come again!* වගේ **Footer text** එකක්.
5. <span class="ui">Save settings</span> තෝරන්න.

</Steps>

විස්තරාත්මකව: [Business settings](/si/business/settings/).

## පියවර 3 — Payment methods

**Cash, Card, QR payment සහ Bank transfer** භාවිතයට සූදානම්. Card, QR සහ bank payments ගන්නේ ඔබේ bank
එකේ terminal එකෙන් හෝ app එකෙන් — GPOS ඒවා cashier type කරන reference එකත් එක්ක record කරනවා විතරයි.

- ඒ හැම එකම ඔබ ගන්නවා නම්, <span class="ui">These are fine</span> තෝරන්න.
- නැත්නම් **Settings → Payment methods** වෙත ගිහින් ඔබ නොගන්න ඒවා **switch off** කරන්න, හෝ ඔබේම method
  එකක් (උදා. gift voucher) සඳහා <span class="ui">Add payment method</span> තෝරන්න.

විස්තරාත්මකව: [Payment methods](/si/business/payment-methods/).

## පියවර 5 — Opening stock

Stock levels හරියට පටන් ගන්න, අද shelves වල තියෙන ප්‍රමාණය දාන්න.

<Steps>

1. **Inventory** → **Opening stock** වෙත ගිහින් **Store** එක තෝරන්න.
2. Spreadsheet එකකින් rows paste කරන්න — **SKU හෝ barcode, quantity, unit cost (අවශ්‍ය නම්)** — නැත්නම්
   CSV එකක් upload කරන්න.
3. <span class="ui">Check</span> තෝරන්න. හැම row එකම හරි නම් <span class="ui">Post opening stock</span> තෝරන්න.

</Steps>

තවම stock track කරන්නේ නැද්ද? Checklist එකේ <span class="ui">Skip for now</span> තෝරන්න.

විස්තරාත්මකව: [Opening stock](/si/inventory/opening-stock/).

## පියවර 6 — පළමු till එක pair කරන්න

<Steps>

1. මුලින්ම **register** එකක් (checkout counter එකක්) add කරන්න: **Branches** වෙත ගිහින්, ඔබේ branch එකේ
   (මුලින් නම **MAIN**) **Registers** යටතේ <span class="ui">Add</span> තෝරන්න. Code එකක් සහ නමක් දෙන්න,
   උදා. `R1` — *Counter 1*.
2. **POS devices** වෙත යන්න. Register එක ළඟ <span class="ui">Set up a till</span> තෝරන්න. **One-time code**
   එකක් සහ QR code එකක් පෙනෙනවා (විනාඩි 15ක් valid).
3. Till device එකේ Chrome හෝ Edge වලින් **[app.gpos.lk/pos](https://app.gpos.lk/pos/)** open කරන්න.
4. **Setup code** එක type කරන්න (හෝ QR code එක scan කරන්න), till එකට *Front counter* වගේ නමක් දී
   <span class="ui">Register this till</span> තෝරන්න.
5. Till එක catalog එක download කරනකම් ඉන්න. මෙතැන් සිට එය **offline** ත් වැඩ කරනවා.

</Steps>

විස්තරාත්මකව: [Set up a till](/si/till/set-up-a-till/).

## පියවර 7 — Staff add කරන්න

<Steps>

1. **Employees** → <span class="ui">Add employee</span> වෙත යන්න.
2. ඔවුන්ගේ **Full name**, **Email** සහ **Initial password** එකක් (අවම අකුරු 12) type කරන්න.
3. **Role** එකක් දෙන්න — උදා. *Cashier* — සහ ඔවුන් වැඩ කරන **Branch** එක.
4. <span class="ui">Create employee</span> තෝරන්න.
5. Till එක unlock කරන්න ඉඩ දෙන්න, employee open කර <span class="ui">Set POS PIN</span> තෝරන්න (ඉලක්කම් 6).
   PIN එක ඔවුන්ට කෙලින්ම කියන්න. ඔවුන්ට **My account** එකෙන් තමන්ම එය set කරන්නත් පුළුවන්.

</Steps>

තනියම වැඩ කරනවාද? Checklist එකේ <span class="ui">I work alone</span> තෝරන්න — නමුත් **My account** එකේ
**ඔබේම POS PIN එක set කරන්න**, මොකද till එක unlock කරන්න එය ඕන.

විස්තරාත්මකව: [Employees](/si/business/employees/) · [Roles and permissions](/si/business/roles/).

## පියවර 8 — පළමු sale එක කරන්න

<Steps>

1. Till එකේ ඔබේ නම තෝරා **PIN එක type කරන්න**.
2. **Shift එකක් open කරන්න**: drawer එකේ තියෙන cash (*opening float*) ගණන් කර
   <span class="ui">Open shift</span> තෝරන්න.
3. **Barcode එකක් scan කරන්න** හෝ product නමක් type කරන්න. Item එක sale එකට එකතු වෙනවා.
4. <span class="ui">Pay</span> තෝරන්න (හෝ **F4** ඔබන්න), **Cash received** type කර
   <span class="ui">Complete sale</span> තෝරන්න. දෙන්න ඕන change එක till එක පෙන්නනවා.

</Steps>

🎉 දැන් sale එක back office එකේ **Sales** සහ **Reports** වල පෙනෙනවා, checklist එකේ **Your business is
ready** කියලා පෙන්නනවා. <span class="ui">Hide checklist</span> තෝරන්න පුළුවන්.

විස්තරාත්මකව: [Making a sale](/si/till/making-a-sale/) · [Cash shifts on the till](/si/till/shifts/).

<Aside type="caution" title="Discounts සහ cash outs ගැන">
මුලින්ම, cashier දෙන **හැම** discount එකකටම සහ **හැම** cash out එකකටම manager ගේ PIN එක ඕන. මේක ලිහිල්
කරන්න [Business settings](/si/business/settings/) හි *Checkout and cash* බලන්න.
</Aside>

  [Returns and voids](/si/till/returns-voids/) බලන්න — සහ **Daily sales** report එක open කරන්න.
