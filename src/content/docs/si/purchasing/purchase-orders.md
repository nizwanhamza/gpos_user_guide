**Purchase orders** plan feature එකක් (ඒකට **Suppliers and goods received** ඕන). ඒක නැත්නම් **Purchase orders** tab එක පෙනෙන්නේ නැහැ —
order එකක් නැතුවත් goods receive කරන්න පුළුවන්. [Plans and features](/si/getting-started/plans/) බලන්න.
:::

**Purchase order (PO)** එකක් කියන්නේ supplier කෙනෙකුගෙන් ඔබ order කරන දේ. POs භාවිතා කිරීම අනිවාර්ය නැහැ —
[order එකක් නැතුව goods receive](/si/purchasing/receiving-goods/) කරන්නත් පුළුවන්.

## Purchase order එකක් හදන්න

1. **Purchasing → Purchase orders** → <span class="ui">New purchase order</span> වෙත යන්න.
2. **Supplier** සහ goods යන **Store** එක තෝරන්න.
3. **Add an item**: name හෝ SKU search කරන්න. හැම line එකකටම set කරන්න:
   - **Unit** — product එකේ unit එක, නැත්නම් **pack** එකක් (උදා. 24ක case එකක් — **pack size** එක දාන්න);
   - **Quantity** සහ **Cost per unit**.
4. අවශ්‍ය නම් **Expected on** සහ **Note** එකක් දාන්න.
5. <span class="ui">Save draft</span> තෝරන්න.

## යවන්න

Order එක open කරලා supplier ට යවන්න <span class="ui">Print / save as PDF</span> තෝරන්න, ඊට පස්සේ <span class="ui">Mark as ordered</span>.

A4 එකේ print වෙන්නේ order එක විතරයි — menus හෝ buttons නැහැ:

- ඔබේ **letterhead** එක — logo එක (තියෙනවා නම්), business නම, address, phone, e-mail සහ tax registration no.;
- **Purchase order** එක, ඒකේ number එක, **Order date**, **Expected delivery** සහ **Status**;
- **Supplier** (ඔවුන්ගේ tax no. සහ payment terms එක්ක) සහ **Deliver to** තැන;
- quantity, cost per unit සහ line totals එක්ක items, **Total** එක සහ ඔබේ **Note** එක;
- පහළින් *Printed … by …*.

E-mail කරන්න print window එකේ **Save as PDF** තෝරන්න. File නම ඔබට suggest කරනවා, උදා. *Purchase order PO-000012*.

## Statuses

| Status | තේරුම |
|--------|-------|
| **Draft** | සකස් කරමින්; තවම edit කරන්න පුළුවන්. |
| **Ordered** | Supplier ට යැව්වා. |
| **Partly received** | Goods සමහරක් ආවා. |
| **Received** | හැම දෙයක්ම ආවා, නැත්නම් order එක close කළා. |
| **Cancelled** | ඉස්සරහට යන්නේ නැහැ. |

## Goods ආවාම

Order එක open කරලා <span class="ui">Receive goods</span> තෝරන්න — [Receiving goods](/si/purchasing/receiving-goods/) බලන්න.

- Supplier ඉතුරු ටික එවන්නේ නැද්ද? <span class="ui">Close (nothing more expected)</span>.
- Order එක ඕන නැද්ද? <span class="ui">Cancel order</span>.

**Open purchase orders** report එකේ තවම එන්න තියෙන goods list කරනවා.
