## GPOS addresses

| | Address | யார் பயன்படுத்துவார்கள் |
|-|---------|--------------------------|
| **Back office** | **[https://app.gpos.lk](https://app.gpos.lk)** | Owners, managers, inventory staff, accountants |
| **Till / POS** | **[https://app.gpos.lk/pos/](https://app.gpos.lk/pos/)** | Cashiers — counter இல் உள்ள computer அல்லது tablet இல் |

<Aside type="caution" title="Features உங்கள் plan ஐப் பொறுத்தது">
GPOS பல plans இல் வருகிறது — உதாரணமாக **Basic**, **Standard** அல்லது **Custom**. இந்த guide இல் உள்ள
சில features (inventory, purchasing, customers, பல branches, expiry tracking போன்றவை) உங்கள் plan இல்
இல்லாமல் இருக்கலாம். Dashboard இல் **Plan** card ஐப் பாருங்கள், மேலும்
[Plans and features](/ta/getting-started/plans/) ஐப் படியுங்கள்.
</Aside>

## GPOS க்குப் புதியவரா?

இன்னும் register செய்யவில்லையா? **[GPOS க்கு apply செய்யுங்கள்](/ta/getting-started/apply/)** —
[app.gpos.lk/register](https://app.gpos.lk/register) மூலம் online ஆக.

உங்கள் business இப்போதுதான் enroll செய்யப்பட்டிருந்தால், **[Quick start](/ta/quick-start/)** இலிருந்து
தொடங்குங்கள். Dashboard இல் தெரியும் setup checklist இன் எட்டு படிகளும் அங்கே உள்ளன. சுமார் ஒரு
மணி நேரத்தில் உங்கள் முதல் sale ஐச் செய்யலாம்.
