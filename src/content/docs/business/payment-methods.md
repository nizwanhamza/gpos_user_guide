Find **Payment methods** in **Settings**. They are the buttons cashiers see when a customer pays.

Card, QR and bank-transfer payments are taken on **your bank's terminal or app**. GPOS only
**records** them, with the reference the cashier types. Card numbers are never stored. **Cash is
always available.**

## Ready-made methods

| Method | Type | Reference required |
|--------|------|--------------------|
| Cash | Cash | No |
| Card | Card (terminal) | Yes |
| QR payment | QR payment | Yes |
| Bank transfer | Bank transfer | Yes |

## Add a payment method

1. Select <span class="ui">Add payment method</span>.
2. Enter the **Name** and, optionally, the **Name in Sinhala** and **Name in Tamil**.
3. Choose the **Type**: Cash, Card (terminal), QR payment, Bank transfer or Other. The type cannot
   be changed later.
4. Tick **The cashier must type the approval code or reference** if you want a reference for every
   payment (recommended for card and QR).
5. Set the **Order** — lower numbers are listed first.
6. Save.

Examples: *LankaQR*, *Gift voucher* (Other), *Amex terminal* (Card).

## Switch off, edit or delete

- <span class="ui">Switch off</span> hides the method on the tills. <span class="ui">Switch on</span>
  brings it back.
- <span class="ui">Edit</span> changes the name, reference rule or order.
- <span class="ui">Delete</span> is only possible for a method that was never used. Used methods
  can only be switched off; past sales keep the name they had.

Tills receive changes with their next sync.
