Cashiers till இல் passwords ஐ type செய்வதில்லை. அவர்கள் தங்கள் பெயரைத் தேர்ந்தெடுத்து **6 இலக்க POS PIN** ஐ type செய்வார்கள்.
இது **offline** ஆகவும் வேலை செய்யும்.

## Unlock செய்யுங்கள்

1. **Who is using the till?** இல் உங்கள் பெயரைத் தேர்ந்தெடுங்கள்.
2. Number pad இல் (அல்லது keyboard இல்) **உங்கள் PIN ஐ type செய்யுங்கள்**.

List இல் நீங்கள் இல்லையா? List **POS PIN உள்ள** மற்றும் **இந்த branch இல் விற்க அனுமதி உள்ளவர்களை** மட்டுமே காட்டும்.
**Employees** இல் உங்கள் PIN ஐ set செய்ய administrator இடம் கேளுங்கள், அல்லது [My account](/ta/getting-started/my-account/) இல்
நீங்களே set செய்யுங்கள். Till க்கு அது அடுத்த sync இல் கிடைக்கும்.

List இல் *No cashiers yet* என இருந்தால், இந்த branch க்கு இன்னும் யாருக்கும் PIN இல்லை.

## தவறான PIN

**5 தவறான PINs** க்குப் பிறகு till அந்த நபரை 5 நிமிடங்களுக்கு lock out செய்யும், ஒவ்வொரு முறையும் காத்திருப்பு நேரம் அதிகரிக்கும்.
எவ்வளவு நேரம் காத்திருக்க வேண்டும் என்று till காட்டும்.

## Lock செய்தல் மற்றும் user ஐ மாற்றுதல்

- Counter ஐ விட்டுச் செல்லும்போது <span class="ui">Lock</span> ஐத் தேர்ந்தெடுங்கள் (அல்லது **F12** ஐ அழுத்துங்கள்). Till மீண்டும் PIN ஐக் கேட்கும்.
- சக ஊழியரிடம் ஒப்படைக்க <span class="ui">Change user</span> ஐத் தேர்ந்தெடுங்கள் — till மீண்டும் *Who is using the till?* க்குச் செல்லும்.
  சக ஊழியர் lock screen இல் <span class="ui">Someone else</span> ஐயும் தேர்ந்தெடுக்கலாம்.
- பயன்படுத்தாமல் **10 நிமிடங்களுக்குப் பிறகு till தானாக lock ஆகும்**.

:::tip
Till இல் செய்யப்படும் அனைத்தும் — sales, discounts, refunds, cash out, approvals — அதை unlock செய்தவர் பெயரிலேயே record ஆகும்.
விலகிச் செல்லும்போது எப்போதும் till ஐ lock செய்யுங்கள்.
:::

## நீங்கள் என்ன செய்யலாம்

உங்கள் role அனுமதிப்பதை till காட்டும். உதாரணமாக, நீங்கள் விற்க முடியாவிட்டால் *You can look up products, but not sell on this
till.* எனக் காட்டும். உங்கள் limit க்கு மேலான discounts, returns, voids க்கு manager இன் approval தேவைப்படலாம் —
[Discounts](/ta/till/discounts/) ஐப் பாருங்கள்.
