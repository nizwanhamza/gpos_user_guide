:::note[உங்கள் plan ஐப் பொறுத்தது]
Till இல் customers க்கு **Customer list** feature தேவை. **Customer discounts** இல்லாவிட்டால் customer இன் discount காட்டப்படாது,
apply செய்யப்படாது. [Plans and features](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

Customer இன் purchase history ஐ வைத்திருக்கவும் அவர்களின் **customer discount** ஐத் தானாக apply செய்யவும், அவர்களை sale உடன் இணையுங்கள்.

## Customer ஐக் கண்டுபிடியுங்கள்

1. <span class="ui">Customer</span> (**F3**) ஐத் தேர்ந்தெடுங்கள். Customer இல்லாமல் pay செய்யச் சென்றால், till **Customer for this
   sale?** எனவும் கேட்கும் — <span class="ui">Add customer</span> அல்லது <span class="ui">Skip — pay now</span>.
2. அவர்களின் **Phone number or name** ஐ type செய்யுங்கள்.
3. அவர்களைத் தேர்ந்தெடுங்கள் (அல்லது **↑ ↓** மற்றும் **Enter**). Sale customer ஐயும், இருந்தால், *… % customer discount* ஐயும் காட்டும்.

அகற்ற <span class="ui">Remove the customer</span> ஐத் தேர்ந்தெடுங்கள்.

## புதிய customer ஐ add செய்யுங்கள்

1. Customer search இல் <span class="ui">New customer</span> ஐத் தேர்ந்தெடுங்கள் — அல்லது யாரும் கிடைக்காதபோது, type செய்த number
   அல்லது பெயருடன் தொடங்க **Add "…" as a new customer** (**Enter**).
2. **Name** மற்றும் **Mobile phone** ஐ உள்ளிடுங்கள் (ஒரு number க்கு ஒரு customer).
3. **May we send offers?** — customer இடம் கேட்டு அவர்கள் ஒப்புக்கொள்வதை மட்டும் tick செய்யுங்கள்: *SMS*, *WhatsApp*, *Email*.
4. <span class="ui">Save and add to sale</span> ஐத் தேர்ந்தெடுங்கள்.

இது offline ஆகவும் வேலை செய்யும்; customer அடுத்த sync இல் back office க்கு அனுப்பப்படுவார்.

Receipt இல் *Customer: {name}* print ஆகும். மேலும் [Customers](/ta/sales/customers/) இல்.
