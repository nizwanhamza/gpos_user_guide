**Customers** හි ඔබේ customer profiles තියෙනවා. Tills **phone හෝ නම** අනුව customers හොයනවා, අලුත් අය add කරනවා (offline ත්),
ඔවුන්ගේ **discount** එක automatic apply කරනවා. Tills වල තියෙන්නේ නම, phone එක සහ discount එක විතරයි.

## Customer කෙනෙක් add හෝ edit කරන්න

1. <span class="ui">Add customer</span> තෝරන්න (නැත්නම් edit කරන්න customer කෙනෙක්).
2. පුරවන්න:
   - **Name** සහ **Mobile phone** — number එකකට එක customer කෙනෙක්, උදා. `077 123 4567`.
   - **Email (optional)**.
   - **Customer discount (%)** — till එකේ automatic apply වෙනවා; manager approval ඕන නැහැ.
   - **Notes** — back office එකට විතරයි; tills වලට යවන්නේ නැහැ.
   - **Marketing consent** — customer එකඟ වුණා නම් විතරක් *SMS*, *WhatsApp* හෝ *Email* tick කරන්න.
   - **Active** — inactive customers tills වලින් අයින් වෙනවා.
3. Save කරන්න.

## Customer details

හැම customer කෙනෙකුටම purchases ගණන, ඔවුන් **Spent** කළ ගණන (returns වලින් පස්සේ), profile එක හැදුවේ කවදාද සහ කොහේද (*at a
till* හෝ *in the admin*), receipts එක්ක **Purchase history** එක, සහ **Consent history** එක පෙන්නනවා.

## Personal data (PDPA)

ශ්‍රී ලංකාවේ **Personal Data Protection Act (PDPA)** අනුව, customer කෙනෙකුට ඔවුන් ගැන ඔබ ළඟ තියෙන දේ අහන්න, නැත්නම් ඒක delete
කරන්න කියන්න පුළුවන්. Customer open කර **Personal data (PDPA)** භාවිතා කරන්න. *Export and erase customer data (PDPA requests)*
permission එක ඕන — default විදිහට owners සහ administrators ට තියෙනවා.

### Customer කෙනෙකුගේ data export කරන්න

<span class="ui">Export data</span> තෝරන්න. Customer ට දෙන්න, ඔවුන් ගැන තියෙන හැම දෙයක්ම — profile, purchases සහ consent history —
තියෙන file එකක් GPOS download කරනවා.

### Customer කෙනෙක් erase කරන්න

1. <span class="ui">Erase customer</span> තෝරන්න.
2. වෙන දේ කියවන්න: ඔවුන්ගේ **නම, phone, email සහ notes සදහටම අයින් වෙනවා**, හැම marketing consent එකක්ම ඉවර වෙනවා. **Sales
   එහෙමම තියෙනවා** (ඔබේ ගිණුම් වලට) නමුත් ගත්තේ කවුද කියලා තවදුරටත් පෙන්නන්නේ නැහැ.
3. Confirm කරන්න **customer ගේ නම type කරන්න**, ඊට පස්සේ <span class="ui">Erase for good</span> තෝරන්න.

ඊට පස්සේ profile එකේ *This customer's personal data was erased on request* පෙන්නනවා, inactive කරනවා, tills වල ඊළඟ sync එකේදී
අතුරුදහන් වෙනවා. ඔවුන්ගේ personal details [audit log](/si/reports/audit-log/) එකෙනුත් clear වෙනවා. **මේක undo කරන්න බැහැ.**

:::caution
ඔවුන්ගේ data export හෝ erase කරන්න කලින්, request එක ඇත්තටම customer ගෙන්මද කියලා check කරන්න.
:::

## Marketing consent

Consent record වෙන්නේ **channel අනුව**, **default විදිහට no**. හැම වෙනසක්ම date එක සහ record කළේ කවුද කියලා තියාගන්නවා, ඒ නිසා
customer කෙනෙක් එකඟ වුණේ හෝ withdraw කළේ කවදාද කියලා පෙන්නන්න පුළුවන්.

**Name හෝ phone** අනුව search කරන්න, **Status** හෝ **With a discount / Without a discount** අනුව filter කරන්න, column එකකින් sort
කරන්න. *Sales by customer* report එකේ spend සහ visits අනුව ඔබේ top customers list කරනවා.
