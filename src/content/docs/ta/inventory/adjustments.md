Reason உடன் correction அல்லது loss ஐ record செய்ய **Inventory → Adjust / write off** ஐப் பயன்படுத்துங்கள். ஒவ்வொரு entry உம் ledger
மற்றும் audit log இல் சேரும்.

## இரண்டு வகைகள்

- **Write-off (stock leaves)** — ஒரு loss: damaged, expired, திருடப்பட்டது, shop இல் பயன்படுத்தியது. இழந்த அளவை உள்ளிடுங்கள்; அவை
  stock இலிருந்து எடுக்கப்படும்.
- **Adjustment (up or down)** — ஒரு correction. மாற்றத்தை உள்ளிடுங்கள்: `3` மூன்றைச் சேர்க்கும், `-2` இரண்டைக் குறைக்கும்.

## Adjustment அல்லது write-off ஐ post செய்யுங்கள்

1. **Choose a store**.
2. **Choose a reason**. Write-off ஆ adjustment ஆ என்பதை reason தீர்மானிக்கும்.
3. **Add an item**: name அல்லது SKU ஐ search செய்து quantity ஐ உள்ளிடுங்கள். தேவையான அளவு items ஐ add செய்யுங்கள்.
4. **Note (optional)** ஐ add செய்யுங்கள்.
5. <span class="ui">Post write-off</span> அல்லது <span class="ui">Post adjustment</span> ஐத் தேர்ந்தெடுங்கள்.

ஒரு shelf அல்லது store ஐ முழுமையாக மீண்டும் எண்ண, அதற்குப் பதிலாக [stock count](/ta/inventory/counts/) ஐப் பயன்படுத்துங்கள்.

## Stock adjustment reasons

Reasons ஐ **Settings → Stock adjustment reasons** இல் manage செய்யுங்கள். Ready-made:

| Reason | Kind |
|--------|------|
| Count correction | Adjustment |
| Found | Adjustment |
| Damaged | Write-off |
| Expired | Write-off |
| Theft / missing | Write-off |
| Own use | Write-off |

உங்கள் சொந்த reason ஐச் சேர்க்க <span class="ui">Add stock reason</span> ஐத் தேர்ந்தெடுங்கள்: பெயரை உள்ளிட்டு **Kind** ஐத் தேர்ந்தெடுத்து
save செய்யுங்கள். பயன்படுத்தாத reasons ஐ switch off செய்யுங்கள்.

**Adjustments & write-offs** report என்ன adjust அல்லது write off செய்யப்பட்டது என்பதை store மற்றும் reason வாரியாக, value உடன் காட்டும்.
