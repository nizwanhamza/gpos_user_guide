:::note[உங்கள் plan ஐப் பொறுத்தது]
**Quick buttons** ஒரு plan feature (அதற்கு **Selling at the counter (POS)** தேவை). அது இல்லாவிட்டால் branch இல் quick picks
ஐ set செய்ய முடியாது, till இல் எதுவும் தெரியாது. [Plans and features](/ta/getting-started/plans/) ஐப் பாருங்கள்.
:::

**Quick-pick buttons** என்பவை till இன் main screen இல் உள்ள product buttons — **barcodes இல்லாத** items க்குச் சிறந்தவை,
உதா. loose காய்கறிகள், bakery items அல்லது ஒரு tea cup. ஒவ்வொரு **branch** க்கும் **40** buttons வரை அதன் சொந்த set உண்டு.

## Buttons ஐ setup செய்யுங்கள்

1. **Branches** க்குச் சென்று branch இல் <span class="ui">Quick-pick buttons</span> ஐத் தேர்ந்தெடுங்கள்.
2. வலது பக்கம் **Search products** செய்து அவற்றை add செய்யுங்கள். **ஒரு** variant உள்ள product உடனே சேரும்; பல variants
   (sizes, colours…) உள்ளதற்கு GPOS **Which …?** எனக் கேட்கும் — variant ஐத் தேர்ந்தெடுங்கள், அல்லது <span class="ui">Back</span>
   ஐத் தேர்ந்தெடுங்கள். ஒவ்வொரு button உம் ஒரு variant.
3. அதிகம் பயன்படும் items ஐ முதலில் வைக்க <span class="ui">Move up</span> / <span class="ui">Move down</span>, ஒன்றை அகற்ற
   <span class="ui">Remove</span> ஐப் பயன்படுத்துங்கள்.
4. Save செய்யுங்கள்.

Tills க்கு மாற்றங்கள் அடுத்த sync இல் கிடைக்கும்.

:::tip
Quick picks ஐ **Sold by: Weight** products உடன் இணையுங்கள்: cashier *Carrots* ஐ tap செய்து, scale இல் வைத்து, எடையை type
செய்வார், price தானாகக் கணக்கிடப்படும்.
:::
