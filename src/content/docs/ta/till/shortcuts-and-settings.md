## Keyboard shortcuts

இதே list till இலும் உள்ளது: மேலே வலது பக்கம் **keyboard button**, அல்லது **Ctrl + K**.

### விற்பனையின்போது

| Key | செயல் |
|-----|--------|
| **F1** | கடைசியாகச் சேர்த்த item ஐ edit செய்யுங்கள்: quantity, variant, discount |
| **F2** | Scan box க்குச் செல்லுங்கள் |
| **F3** | Sale க்கு customer (phone அல்லது பெயர் மூலம் தேடுங்கள், அல்லது புதியவரை add செய்யுங்கள்) |
| **F4** | Pay. Customer இல்லாவிட்டால் till முதலில் கேட்கும்: **F3** (அல்லது Enter) ஒருவரைச் சேர்க்கும், மீண்டும் **F4** customer இல்லாமல் pay செய்யும் |
| **F5** | கடைசி receipt ஐ மீண்டும் print செய்யுங்கள் |
| **F6** | Sale ஐ hold செய்யுங்கள் |
| **F7** | Hold செய்த sales (resume அல்லது discard) |
| **F8** | முழு sale க்கும் discount |
| **Num +** / **Num −** | கடைசி item இல் ஒன்று கூடுதல் / குறைவு (number pad, எதுவும் type செய்யாதபோது) |
| **Ctrl + Delete** | Sale ஐ clear செய்யுங்கள் (முதலில் கேட்கும்) |
| **↑ ↓**, **Enter** | Search result (அல்லது customer) ஐத் தேர்ந்தெடுத்து add செய்யுங்கள் |

### Pay செய்யும்போதும் sale க்குப் பிறகும்

| Key | செயல் |
|-----|--------|
| **F4** அல்லது **Enter** | Pay window இல்: sale ஐ complete செய்யுங்கள் (அல்லது part payment ஐ add செய்யுங்கள்) |
| **Enter** அல்லது **F5** | Sale க்குப் பிறகு: receipt ஐ print செய்யுங்கள் |
| **Esc** | Sale க்குப் பிறகு: Go Green — receipt இல்லை |
| **Enter** | Customer search இல் யாரும் கிடைக்காதபோது: type செய்த number அல்லது பெயரைப் புதிய customer ஆக add செய்யுங்கள் |

### Shift, sales மற்றும் till

| Key | செயல் |
|-----|--------|
| **F9** | Sales: receipt ஐக் கண்டுபிடியுங்கள், reprint செய்யுங்கள், **A4** இல் print செய்யுங்கள், items ஐ return அல்லது void செய்யுங்கள் |
| **F10** | Shift: cash in/out, X report (receipt printer அல்லது **A4**), close |
| **F11** | Full screen on / off |
| **F12** | Till ஐ lock செய்யுங்கள் |
| **Ctrl + K** | Keys list |
| **Esc** | Open ஆக உள்ள window ஐ close செய்யுங்கள் |

நேரடியாக type அல்லது scan செய்யத் தொடங்கலாம் — till அதை scan box க்கு அனுப்பும். Function keys ஒருபோதும் scan box க்குச் செல்லாது,
எனவே barcode scanner உடன் மோதாது.

### Browser shortcuts off செய்யப்பட்டுள்ளன

தவறுதலாக அழுத்தும் key page ஐ reload செய்வது, screen ஐ print செய்வது அல்லது sale இன் நடுவில் till ஐ விட்டு வெளியேறுவதைத் தடுக்க,
till browser இன் சொந்த shortcuts ஐப் புறக்கணிக்கும் — reload (F5, Ctrl + R), print (Ctrl + P), find, zoom, back மற்றும் forward,
text fields க்கு வெளியே right-click menu. Copy, paste, cut, undo, select all ஒவ்வொரு field இலும் தொடர்ந்து வேலை செய்யும்.

**Ctrl + W**, **Ctrl + T**, **Alt + F4** போன்ற சில keys computer க்குச் சொந்தமானவை, எந்த web page உம் அவற்றை off செய்ய முடியாது.
அவற்றைத் தவிர்க்க till ஐ full screen இல் [installed app](/ta/till/set-up-a-till/) ஆக run செய்யுங்கள்.

## Till settings

Till இன் சொந்த settings ஐக் கண்டுபிடிக்க sync panel ஐ open செய்யுங்கள் (status bar ஐத் தேர்ந்தெடுங்கள்). அவை **இந்த device க்கு**
மட்டுமே பொருந்தும்.

### Receipt printing

- **Receipt paper** — *58 mm* அல்லது *80 mm* (default 80 mm).
- **Receipts** — தானாக print செய்ய **Print after each sale** ஐ tick செய்யுங்கள்.

Receipts browser மூலம் device இல் install செய்த printer க்கு print ஆகும். Receipt printer ஐ **default printer** ஆக set செய்து,
Chrome அல்லது Edge இன் print dialog இல் headers மற்றும் footers ஐ off செய்யுங்கள். Dialog இல்லாத silent printing க்கு, Chrome இன்
*kiosk printing* option பற்றி உங்கள் IT support இடம் கேளுங்கள்.

என்ன print ஆகும் (பெயர், header lines, footer, tax number) என்பது [Business settings](/ta/business/settings/) இல் *Receipts* பகுதியில் set செய்யப்படும்.

### Screen

- **Screen** (sync panel இல்) — browser அனுமதித்தால், till open ஆக இருக்கும் வரை screen ஐ on ஆக வைத்திருக்கும்.
- **Top bar** இல்: பெரிய buttons மற்றும் prices க்கு <span class="ui">Larger text</span> / <span class="ui">Normal text</span>, மற்றும்
  <span class="ui">Full screen</span> / <span class="ui">Exit full screen</span>.

### Scan sounds

Scan செய்யும்போது beep ஐ **On** அல்லது off செய்யுங்கள்.
